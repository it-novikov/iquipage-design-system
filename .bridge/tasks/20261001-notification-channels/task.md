# Каналы уведомлений: почта и Telegram, пачки и оформление

## Цель

Владелец просит выбирать, куда приходят внешние уведомления: на почту аккаунта или в Telegram, и получать их пачками, понятными с первого взгляда. Сейчас (#40) есть только Telegram, по сообщению на событие. Результат: человек включает почту и/или Telegram, воркер собирает пачки за окно и отправляет одно аккуратное сообщение или письмо без списков, с перепроверкой каждого пункта.

## Рамки

- **Входит:** каналы в настройках человека, переключатель проекта «Внешние уведомления», очередь пачек, шаблоны Telegram и письма, отписка в один клик, миграции 056–059, тесты, документация, превью.
- **Не входит:** push в браузер, mailto-отписка через входящую почту, колокольчик Рабочего стола, изменение текста колокольчика.
- **Ограничения:** миграции только V20261001000056–059; не трогать файлы feature/ai-connections и feature/planning-containers; Docker только colima-sprintique-vnext-qa; не слать настоящих писем и сообщений; без продакшена.

## Приёмка

- [x] A1. Настройки → Для меня → «Уведомления»: каналы Почта (адрес аккаунта, только чтение) и Telegram (подключение как сейчас), виды событий для выбранных каналов; колокольчик всегда; по умолчанию Telegram включён после подключения, почта выключена
- [x] A2. Переключатель проекта «Внешние уведомления» вместо «Уведомления в Telegram», то же право, существующая настройка перенесена
- [x] A3. Пачки на человека и канал: окно 5 мин Telegram и 15 мин почта (env), раньше при 20; перепроверка каждого элемента, схлопывание по задаче, повторы с бэкоффом, 429, 403 — отвязка, учёт по пачке и элементу, не старше 24 ч, часовой пояс человека
- [x] A4. Оформление без списков: Telegram HTML (заголовок, проект, задача ссылкой, причины, кнопки, деление по 4096 на границах задач); письмо multipart/alternative, табличный шаблон IQUIPAGE, тема, прехедер, кнопка на задачу, подвал, List-Unsubscribe one-click (RFC 8058) с подписанным токеном
- [x] A5. Миграции V20261001000056–059 с RLS FORCE, jOOQ и контракты; интеграционные тесты каналов, окна, схлопывания, перепроверки, MIME, токена отписки, деления, повторов
- [ ] A6. Документация (operations.md, ADR), превью письма светлое/тёмное и макет Telegram, гейты npm test и verify-vnext, PR на русском, не слит
