# SPR-16/17: документация проекта и материалы задач

## Цель

Хранить общие инструкции и требования в проекте, находить их и открывать из задач без копирования текста между описаниями. В SPR-16 дать несколько именованных ссылок на дизайн и документацию с компактными пустыми состояниями. В SPR-17 добавить дерево страниц, редактор, поиск, историю и архив с сохранением данных и авторства.

## Рамки

- **Входит:** исследование и подробный план; после выбора прав — project wiki, история/восстановление, поиск/архив, внешние и внутренние материалы задачи, проверки и разрешённая поставка.
- **Не входит:** публичные страницы, редактирование в реальном времени, отдельные ограничения каждой страницы, новая система файлов. Файлы остаются в существующих вложениях задач.
- **Ограничения:** пользователь подтвердил общие TASKS_READ/TASKS_WRITE, включая сервисные аккаунты. UI — GPT 6 Astra, сервер/контракты/миграция — root. Только versioned public DS; никакого runtime SQL в MCP.

## Приёмка

- [x] A1. Создание, чтение, дерево, редактирование, поиск, архив и возврат wiki работают на настоящем backend.

- [x] A3. Несколько материалов дизайна/документации сохраняются отдельно от описания задачи, wiki ссылки и backlinks соблюдают границы проекта.
- [x] A4. Выбранные права, runtime FORCE RLS, ограниченный доступ сервисов и безопасные ссылки проверены реальными сценариями.
- [x] A5. UI Astra функционален и эстетичен в DS, пустое/ошибка/read-only/mobile/recovery состояния проверены.
- [x] A6. Fresh/existing миграция, два ревью, полный gate и совместимый откат проверены до merge и production cutover.

## Решения

Wiki — самостоятельный модуль существующего монолита, task links не используются вместо материалов. Внешние HTTP(S) ссылки сервер не скачивает. Restore создаёт новую текущую версию; архив не удаляет историю. UI первой волны SPR21/22/24/37/38 поставляется отдельно.
- **D1** (2026-10-11) Владелец отклонил текущую UI-композицию документации. Полная пересборка начинается с исследования командой, плана и независимого ревью потенциального дизайна; лишь после исправлений — реализация Astra. Серверные контракты, сохранность данных и общие права задач сохраняются.

## Вопросы

Вопрос о правах закрыт владельцем: читатели задач читают документацию, редакторы задач её изменяют, включая сервисные аккаунты.
