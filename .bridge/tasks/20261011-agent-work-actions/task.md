## Цель

## Рамки

- **Входит:** публичные стили рабочих компонентов DS; композиция агентской вкладки и краткий контекст действия в основной вкладке; проверки, PR и разрешённая выкладка.
- **Не входит:** изменение серверного API, схемы, прав, миграций, принятие production-результатов от имени человека.
- **Ограничения:** UI реализует GPT 6 Astra; exact DS tarball; без увеличения бюджета; сохранить отступы заголовка 25/25 desktop и 21/21 mobile. Человек явно принимает результат, ошибки CAS не теряют черновик.
