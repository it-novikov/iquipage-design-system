## Decision and alternatives

First implement A only inside data-label=wide: natural-height controls/static text, full captions, explicit existing carriers and CSS wrapping with no-grow label. Value uses remaining space or its own line. One shared rhythm rather than promising exact36px and conditional4/12 simultaneously. Keep line-height from existing typography roles. No observer, remount, text-measuring JS, global viewport query or consumer L/V controls.

Numbers7U/14U are a trial, not proven useful widths. B (explicit container composition with full-width labels) remains available if A causes unnecessary label lines, poor density, broken grouping or disproportionate implementation complexity. Existing two-column wrapping alone is the causal reference, not an acceptable answer to a value squeezed into a few characters. No layout is chosen for mathematical symmetry.

## High-risk design questions

1. Scenarios/roles: public editable select/date/combobox/tag and static facts, normal and enlarged text, wide/tight parent. Read-only display has no new action. Task adoption follows separately.
2. Data/privacy: deterministic synthetic fixture only; no production data, auth, permissions or backend change.
3. Errors/concurrency/retries: no mutation/transport logic change. Assert one UI intent and preserved control identity. Container-only popup position is diagnosed on54/55; a pre-existing deficit is not repaired by a blanket overlay rewrite.
4. Limits/load: no added dependency or runtime measurement. Long captions/unbroken text grow vertically; native inputs remain single-line. No arbitrary line-count limit or shrink-to-fit text.
5. Dependencies/degradation: exact54 control archive and exact private55 candidate, public exports only. Native CI required; local /proc Chromium/JDK/TS7 limitations remain NOT_RUN, no repeated attempts.
6. Compatibility/rollback: only wide-list changes. External data-columns/strip/reference controls retain their rules. Product vendor54 is unchanged; discard private55 or revert the scoped library delta if A fails. No migration/deployment, therefore production rollout/observation and DB rollback N/A at this trial.
7. Alternatives/simplicity: actual carriers rather than new universal wrapper; existing spacing/radius roles first. Missing empty-readonly tag caption and product .tdr-pill are explicit separate scope, not hidden additions.
