# Sprintique: различимые компактные сигналы и страницы на всю ширину с рабочими отступами

## Цель

Блокировка занимает слишком много места и конкурирует с приоритетом. Нужен компактный ряд с одинаковым выравниванием, где приоритет и блокеры легко различаются. Страницы используют доступную ширину без прежних ограничений, сохраняя рабочие горизонтальные отступы по дизайн-системе и внутренние поля компонентов. Последнее уточнение владельца D4 заменяет прежнее требование zero-padding.

## Рамки

- **Входит:** Все поверхности приоритета/блокеров и внешний layout всех типов страниц; публичное дополнение DS при необходимости; фактическая браузерная проверка и разрешённая поставка.
- **Не входит:** Изменение backend, прав, схемы, смыслов приоритетов и зависимостей.
- **Ограничения:** UI автор GPT 6 Astra, root ведёт операции. Versioned public DS, никаких private overrides. Push, merge и deployment авторизованы владельцем ранее в этой задаче.

## Приёмка

- [ ] A1. Приоритет и блокировка компактны, выровнены по высоте и визуально различимы; причина доступна без потери контекста.
- [ ] A2. Страницы используют доступную ширину без прежних caps, с рабочими полями24px desktop/16px mobile; внутренние отступы и ширина текста сохранены, элементы не обрезаются.
- [ ] A3. Светлая/тёмная темы, клавиатура, длинные названия, разные приоритеты и несколько блокеров проверены; функции и права сохранены.
- [ ] A4. Точный public DS, сборка, полный CI, независимые ревью и production проверка подтверждены.
