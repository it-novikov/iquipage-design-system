# Ревью R3

## Замечания

- **F1** [P3] `products/sprintique/server/src/main/kotlin/com/sprintique/workbench/application/WorkbenchRows.kt:138` — `waiting.ownerNow`, `owner` и `updates.latest.actor` называют по имени человека, который ушёл из проекта. ADR W5 п. 6 требует имени не показывать, а `expectedAssignee` в той же строке его уже скрывает. Ветка `delegated_orphaned` тестами не покрыта.
  Сценарий: Алиса поручила T Борису, Бориса удалили из проекта. В строке «Жду» причина «Исполнитель больше не в проекте», а в `ownerNow.name` всё равно «Борис».
  Решение: [fixed 299931f] имена исполнителя и автора события отдаются только участникам проекта, id остаётся; для задачи, переданной ушедшему, текст «исполнитель больше не в проекте»; тест W19.

- **F2** [P3] `products/sprintique/server/src/main/kotlin/com/sprintique/workbench/application/PersonalState.kt:205` — `rank` выполняет весь запрос снимка (`joinedOrder`), держа строку проекта `FOR KEY SHARE`. Всё это время общие записи в проекте ждут.
  Сценарий: у Алисы 2000 участий. Пока идёт её «вверх», `PUT /tasks/...` Бориса в том же проекте ждёт 1–4 с.
  Решение: [fixed 299931f] список видимых задач читается до блокировок, под блокировкой читаются только их текущие ранги.

- **F3** [P3] `products/sprintique/server/src/main/kotlin/com/sprintique/configuration/FeatureFilter.kt:36` — Раскладка Обзора закрыта флагом плана `workbench_plan_horizon`.
  Сценарий: план откатили флагом, и Обзор получает 404 на свою раскладку.
  Решение: [fixed 299931f] `preferences` открыты флагом `workbench_read_internal`; ADR W6 п. 8; проверка в W10.
