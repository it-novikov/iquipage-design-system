# Граф связей v2: «Ступица» со словами на рёбрах (DS iq-relation-map)

## Цель

Владелец одобрил второй раунд графа связей в ящике задачи: раскладка «Ступица» (вариант 1), смысл связи на рёбрах как в «Потоке» (вариант 2), центр из двух строк с воздухом. Текущий iq-relation-map с дорожками и вставкой сжимал узлы до 149 px и прятал смысл в заголовках. Результат: DS 0.6.0-vnext.26 с новым iq-relation-map, принятый в Sprintique, гейты зелёные, PR в main.

## Рамки

- **Входит:** DS `relation-map.js` и правила `.rm-*` в `foundation.css`, контракты DS, релиз vnext.26 и его принятие в продукте, правило вставки в `board.css`.
- **Не входит:** «Рельс» и любые узкие раскладки (у Sprintique нет мобильного UI), изменение API хоста, диалог «Связать задачи».
- **Ограничения:** только токены IQUIPAGE, обе темы; Docker только через colima-sprintique-vnext-qa; чужие worktree, стенды и прод не трогать.
