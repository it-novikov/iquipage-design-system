# Связи и файлы при создании задачи

## Цель

Владелец: «Нет возможности добавить связь и файлы при создании задачи». В окне новой задачи «Связи» говорили «можно добавить после создания», а «Файлы» стояли в самом низу, под длинным шаблоном описания. Нужно, чтобы связи и файлы добавлялись прямо в форме и оказывались в задаче после «Создать задачу», без дублей при повторе и без молча недоделанного состояния. Проверка: тесты API и UI, скриншоты 1440×1000 в двух темах.

## Рамки

- **Входит:** раздел «Связи» в окне создания (карта, выбор задачи и вида связи, включая родителя), последовательное сохранение связей с повтором по пункту, порядок файлов, тесты.
- **Не входит:** изменения сервера и миграции (API уже умеет всё нужное), DS.
- **Ограничения:** только публичные API IQUIPAGE DS, права tasks.write, поведение повтора загрузки из #37, только десктоп.

## Приёмка

- [x] A1. В окне новой задачи есть «Связи» с тем же выбором задачи и вида связи, что в карточке, и «Файлы» с зоной и списком; всё выбранное оказывается в задаче после «Создать задачу»
- [x] A2. Повтор после потерянного ответа не создаёт вторую задачу, связь или файл; ошибка связи видна по пункту и повторяется отдельно
- [x] A3. Неудачная загрузка не теряет задачу и повторяется новой загрузкой (#37); права tasks.write соблюдены
- [x] A4. Тесты API и UI, скриншоты 1440×1000 в двух темах, гейты npm test, check:boundaries и verify-vnext зелёные, PR открыт и не слит

## Решения

- **D1** (2026-10-08) Файлы едут в самой команде создания: загрузки ставятся заранее на id будущей задачи и связываются через attachmentIds в её транзакции (так сервер умеет давно) — почему: это уже атомарно, менять сервер не нужно
- **D2** (2026-10-08) Связи создаются после задачи, каждая своей идемпотентной командой PUT task-links/{id} с постоянным id и ключом — почему: создание с релизом или родителем идёт через команду планирования (предпросмотр и коммит), а вносить туда связи значит менять движок планирования; последовательный поток с повтором по пункту безопасен и не требует миграций
- **D3** (2026-10-08) В окне создания связи показывает та же карта iq-relation-map, что в карточке, с центром «Новая задача»; ошибки по пунктам — строки под картой с «Повторить» — почему: владелец предпочитает граф любому списку, а DS-компоненты те же
