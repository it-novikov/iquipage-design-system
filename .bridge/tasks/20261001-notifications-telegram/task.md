# Уведомления и доставка в Telegram (перенос из пилота)

## Цель

В пилоте Sprintique человек узнавал о назначении, упоминании и сроке задачи из колокольчика и Telegram; в vNext этого нет. Нужны личные уведомления о событиях, которые требуют действия человека, и их доставка в Telegram с настройками человека и переключателем проекта. Результат: события создаются сервером в транзакции причины, видны в колокольчике шапки и приходят в Telegram, когда он подключён.

## Рамки

- **Входит:** события assigned, mention, request, deadline; колокольчик в шапке проекта; раздел «Уведомления» в настройках; привязка Telegram, вебхук, очередь доставки в воркере; переключатель проекта; миграции 042–045, тесты, документация.
- **Не входит:** колокольчик в шапке Рабочего стола (PR #38 меняет её), почта, push, автодополнение @ в редакторе, перенос уведомлений пилота.
- **Ограничения:** миграции только V20261001000042–045; не трогать libraries/iquipage relation-map, ui/src/board/link-view.js, board.css, личную панель Рабочего стола; Docker только через colima-sprintique-vnext-qa; без продакшена.

## Приёмка

- [ ] A1. События уведомлений в транзакции причины: назначение (не себе), упоминание @Имя в обсуждении, запрос Рабочего стола адресату, срок задачи (воркер, ~за сутки в часовом поясе человека); без самоуведомлений, дедупликация по ключу, проверка доступа, сервисные аккаунты не получают
- [ ] A2. Колокольчик в шапке проекта: число непрочитанных (только >0), поповер 20 + курсор, строка на уведомление, относительное время, точка непрочитанного; клик открывает задачу и отмечает прочитанным; «Прочитать все»; компоненты DS
- [ ] A3. Настройки → Для меня → «Уведомления»: Telegram по типам событий (в продукте всегда включено), по умолчанию всё включено после подключения Telegram
- [ ] A4. Telegram: конфигурация через env (скрыто без неё), одноразовый токен привязки (SHA-256, 15 мин), вебхук с секретом и идемпотентностью по update_id, /start и /stop, переключатель проекта (по умолчанию включён, право project.settings), исходящая очередь с повторами (5 попыток, 429 retry_after, 403 → отвязка)
- [ ] A5. Миграции V20261001000042–045 с RLS FORCE, jOOQ перегенерирован, контракты обновлены; интеграционные тесты событий, вебхука, доставки (фейковый Telegram API), настроек
- [ ] A6. Документация: operations.md (env, регистрация вебхука, nginx), решение (ADR); гейты npm test и verify-vnext зелёные; визуальная проверка; PR в main, не слит
