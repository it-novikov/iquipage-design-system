# Уведомления и доставка в Telegram (перенос из пилота)

## Цель

В пилоте Sprintique человек узнавал о назначении, упоминании и сроке задачи из колокольчика и Telegram; в vNext этого нет. Нужны личные уведомления о событиях, которые требуют действия человека, и их доставка в Telegram с настройками человека и переключателем проекта. Результат: события создаются сервером в транзакции причины, видны в колокольчике шапки и приходят в Telegram, когда он подключён.

## Рамки

- **Входит:** события assigned, mention, request, deadline; колокольчик в шапке проекта; раздел «Уведомления» в настройках; привязка Telegram, вебхук, очередь доставки в воркере; переключатель проекта; миграции 042–045, тесты, документация.
- **Не входит:** колокольчик в шапке Рабочего стола (PR #38 меняет её), почта, push, автодополнение @ в редакторе, перенос уведомлений пилота.
- **Ограничения:** миграции только V20261001000042–045; не трогать libraries/iquipage relation-map, ui/src/board/link-view.js, board.css, личную панель Рабочего стола; Docker только через colima-sprintique-vnext-qa; без продакшена.

## Приёмка

- [x] A1. События уведомлений в транзакции причины: назначение (не себе), упоминание @Имя в обсуждении, запрос Рабочего стола адресату, срок задачи (воркер, ~за сутки в часовом поясе человека); без самоуведомлений, дедупликация по ключу, проверка доступа, сервисные аккаунты не получают
- [x] A2. Колокольчик в шапке проекта: число непрочитанных (только >0), поповер 20 + курсор, строка на уведомление, относительное время, точка непрочитанного; клик открывает задачу и отмечает прочитанным; «Прочитать все»; компоненты DS
- [x] A3. Настройки → Для меня → «Уведомления»: Telegram по типам событий (в продукте всегда включено), по умолчанию всё включено после подключения Telegram
