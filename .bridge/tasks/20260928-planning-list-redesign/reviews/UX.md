### 2. Контейнер релиза/спринта/бэклога

**Строка 1:** шеврон · чекбокс группы (виден при hover или когда есть выделение) · **Название** (h2) · мягкий бейдж состояния (`.iq-badge.soft`: «Идёт» info, «Запланирован» planned; при просрочке бейдж становится danger «Просрочен на 3 дня» — состояние и время не дублируются) · тихая подпись «Спринт, 23.09 – 07.10» (тип и даты — одна фраза, без отдельного слова «Спринт»). Справа — **одно** главное действие по состоянию: идёт → «Открыть доску»; запланирован → «Начать спринт»; бэклог → «Добавить задачу». Всё остальное («Завершить», «Добавить задачу», «Изменить сроки», «Отменить», «Результат») — в меню «…». «Завершить спринт» на одной высоте с «Открыть доску» — это равный вес у рутинного и необратимого действия.

Ноль-факты не показываются.

**Бэклог:** без состояния, дат и прогресса; строка 2 — «9 задач, 2 черновика»; фон `--iq-surface` оставить. Идущий спринт визуально выделить — CSS `.pn-group[data-state=active]` уже есть, но `index.js` не ставит `dataset.state` (баг, атрибут никогда не применяется).

**Убрать:** метку «Задачи» перед «2 задачи», дубль «прогресс-бар + Готово 0 из 2», заполненные бейджи (DS перешёл на soft в плотных списках), «Добавить задачу» как кнопку заголовка у запланированных.

### 3. Иерархия эпик → подзадачи

**Вариант A — отступ без линий:** дети сдвинуты на один шаг (16px), перед ключом тихая стрелка «↳», глубина >2 визуально не растёт. Просто, но при 4 уровнях и `contextOnly`-родителях связь теряется, а на телефоне отступ спорит с двухстрочной строкой.

**Вариант B — вложенный блок (язык доски):** родитель — обычная строка с чипом «готово 1 из 2» (мини-`ui.progress` + счётчик) и шевроном; при раскрытии под ней появляется **инсет-панель** (скруглённая, фон `--iq-surface`, как «relations sit on an inset panel» в drawer) с детьми **без отступа** и без ключей-линий; последняя строка панели — тихое «+ Подзадача». Уровень 3–4 — та же панель на один тон глубже, отступ не растёт. Ребёнок в другом релизе (`parentContext`) показывает под названием чип «Часть: Эпик: совместная работа» по названию, а не «Родитель: SPQ-1» (так решено для доски). `contextOnly`-родитель — заголовок панели: приглушён, без чекбокса, но название кликабельно (сейчас `<span>` — открыть нельзя), с подписью «показан для контекста».

**Выбираю B.** Он продолжает уже принятое решение по доске (без отступов, «готово N из M», раскрытие в компактный список), не ломается на границах страниц (`lastChildren` считает «локоть» по загруженной странице — «Показать ещё» и windowing рвут линию), не съедает 4×32px ширины на глубине 4 и естественно живёт на мобильном. Решение «подзадачи висят под стрелкой родителя, родитель показывает число» сохраняется — меняется только рисунок линий.

### 4. Строка задачи

Порядок: `[⋮⋮ при hover] [чекбокс при hover/выделении] [сигнал типа/приоритета] SPQ-8 Название [Черновик] [готово 1 из 2] | Статус | Исполнитель | Срок`.

- **Сигнал** — DS `taskSignal({priority,type})` (уже на карточках): эпик/баг/высокий/критический как глиф 16px. Сейчас приоритет закодирован **только цветом названия** (`taskEmphasis`: фиолетовый/янтарный/красный) — читается как разные состояния ссылок, нарушает WCAG 1.4.1 и в тёмной теме глохнет. Оставить цвет только для critical.
- **Ключ** — mono, приглушён, не кнопка. **Ручка** ⋮⋮ появляется слева от ключа при hover/focus (24px резерв), `cursor:grab` на ней; при сортировке не «вручную» ручка скрыта, а не молча не работает. Между карточками — подсветка заголовка-дропзоны; внутри — 2px акцентная линия. Клавиатурный путь «Порядок…» оставить.
- **Название** — единственная ссылка, всегда `--iq-ink`, открывает drawer.
- **Статус** — `.iq-badge.soft`, клик открывает `iq-select appearance="pill"` в поповере (переходы разрешены workflow).
- **Исполнитель** — `ui.personAvatar` + имя (≥1280px), только аватар уже; пустой — пунктирный кружок, не текст «Не назначен». Клик — `iq-select searchable` с аватарами в поповере, а не модальный `formDialog` с preview/commit: тот же `PlanningOperation`, но без окна.
- **Срок** — `iq-date-field` в поповере; красный просрочен, янтарный ≤2 дней (как в drawer); пустой — «—».
- **Выбор** — фон `--iq-accent-soft` (есть), чекбоксы показываются при hover и пока выделение непусто; Shift-диапазон есть. Bulk-панель — **плавающая внизу** (sticky), а не четвёртый ряд сверху за 700px от выделенных строк.

### 5. Тулбар

Два ряда вместо трёх:
1. **Заголовок:** «Планирование» · сегмент «Список / Гант / Календарь» рядом с заголовком; справа «Новый релиз» (secondary), «Новая задача» (primary).
2. **Инструменты:** «Все / Черновики / Готовы» · «Порядок: вручную ▾» · «Фильтры (2)» · активные фильтры как удаляемые чипы (так уже на доске); справа «Текущие / Архив» (в Ганте скрыт, как сейчас).
Bulk-панель не занимает ряд — она внизу. Первая строка задачи поднимается с ~565px до ~330px на 1250px-экране.

### 6. Состояния

- **Загрузка:** DS-скелет с задержкой 180ms уже есть — оставить; для группы скелет из 3 строк внутри карточки.
- **Пусто:** `.iq-empty.compact` внутри карточки. Релиз: «Пока нет задач — перетащите из бэклога» + «Добавить задачу». Бэклог: «Бэклог пуст». Фильтр: «Ничего не подходит под условия» + **кнопка «Сбросить фильтры»** (сейчас только текст). Страница: `ui.empty` с двумя действиями.
- **Ошибка:** алерт внутри карточки с «Повторить» (есть). Глобальная ошибка не должна блокировать всё (`locked` сегодня гасит даже переключатель видов).
- **Показать ещё:** задачи — автоподгрузка по `IntersectionObserver` (уже используется для групп) плюс тихая строка «Показано 100 из 240»; релизы — кнопка оставить, их мало.

### 7. Мобильная версия

Ломается: ключ скрыт DS-правилом (`.iq-work-list-id{display:none}` ≤700px) — **перетаскивание исчезает полностью**; строка раскладывается в три этажа с сиротой «Без даты»; действия заголовка уходят третьей строкой между названием и фактами; факты переносятся на 3 строки; чекбокс — постоянный 44px столбец.

Должно быть: строка в **две линии** — «сигнал · название · Черновик-точка» и «статус-пилюля · срок (если есть) … аватар справа»; ключ — в drawer. Тап открывает, долгий тап выделяет, bulk-панель sticky снизу, drag по ручке при долгом тапе. Заголовок: название + soft-бейдж, одна строка фактов caption, одно главное действие иконкой + «…». Тулбар — одна горизонтально прокручиваемая строка чипов; вид — сегмент под заголовком. Прокрутка страницы (не вложенная) — уже правильно.

### 8. Главные дефекты

1. **Приоритет/тип только цветом названия** — нет легенды, конфликт с семантикой ссылок, WCAG 1.4.1.
2. **Тёмная тема: soft-warning бейджи «На проверке» и «Черновик» без видимого текста** (скриншот) — contrast-баг токена.
3. **Срок строки не тонируется** — 30.09 при сегодняшнем 28.09 выглядит как «Без даты»; job «увидеть просрочку» не решается.
4. **Ручка = ключ без аффорданса**; на телефоне ключ скрыт → drag недоступен; при сортировке не «вручную» drag молча не работает.
5. **Линии дерева хрупки**: «локоть» считается по загруженной странице, глубина 4 съедает 128px, линии пересекают разделители строк.
6. **Три ряда шапки + bulk-бар сверху**: 45% первого экрана — chrome; панель действий далеко от выделения.
7. **Избыточность заголовка**: «Задачи 2 задачи», прогресс-бар + текст дважды, «Релиз 2.4» с подписью «Спринт», заполненные бейджи в плотном списке.
8. **Быстрая правка через модалку**: исполнитель/срок — окно с preview/commit ради одного поля (3 клика против 1 поповера).
9. **`parentContext` показывает «Родитель: SPQ-1»** вопреки решению «называть родителя по названию»; `contextOnly`-родитель не открывается.
10. **Идущий спринт не выделен** — `dataset.state` не выставляется; заголовок колонок есть только в первой карточке, у бэклога внизу его нет; «Не назначен»/«Без даты» текстом в каждой пустой ячейке — шум.

### Решение в одном абзаце

Список остаётся набором карточек «спринт / релиз / бэклог» с двухстрочным заголовком, но заголовок получает мягкий бейдж состояния (danger при просрочке), одну тонкую полосу прогресса и факты готовности (готово, черновики, без исполнителя, просрочено, дни), одно главное действие и меню. Строка задачи получает сигнал типа/приоритета, ключ без роли ручки, скрытую до hover ручку ⋮⋮, тонированный срок, поповеры вместо модалок для статуса/исполнителя/срока и чекбоксы по hover. Иерархия рисуется языком доски — родитель с «готово N из M», раскрывающийся во вложенную инсет-панель без линий и отступов; родитель из другого релиза называется по названию. Шапка сжимается до двух рядов, bulk-панель уезжает вниз, на телефоне строка — две линии, а drag живёт на ручке. Серверу нужны `drafts/unassigned/overdue` на группу и `parentTitle` на строку.
