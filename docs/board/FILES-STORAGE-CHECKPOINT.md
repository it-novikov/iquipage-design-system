# Вложения: изолированный слой хранения, 2026-09-11

Продолжение B2.1. Пользователь разрешил реализацию и PR со всеми доработками.
Готовая пользовательская поставка по-прежнему Board B2.

Добавлен `packages/maps/server/attachment-store.mjs`:
- приём проверенного файла во временное хранилище без создания задачи;
- оригинал и производные изображения — отдельные двоичные файлы;
- идемпотентность повторной загрузки, проверка совпадения содержимого;
- отдельная проверка проекта, задачи и автора временной загрузки;
- откат новых двоичных файлов при ошибке записи метаданных;
- отмена до фиксации, удаление временной загрузки и сборка истёкших файлов;
- последовательная фиксация и ограничение параллельной обработки.

Девять изолированных тестов используют временные каталоги и контрактный
репозиторий. Они проверяют этот модуль, не HTTP-маршруты или интерфейс.
Полное принятие файла вместе с задачей НЕ ПРОВЕРЕНО и НЕ ПОДКЛЮЧЕНО.

Блокировка: вызов изменения model.js, workspace-model.js, repository.js и
file-repository.mjs для атомарной фиксации task/attachment отклонён инструментом
с сообщением о неопределённом статусе безопасности. Один повтор идентичного
вызова получил тот же результат. Обход и применение другим способом не выполнялись.
`git status` подтвердил отсутствие изменений этих файлов.

Остаётся: разрешение операции в среде, атомарное подключение общего хранилища,
браузерный Blob-адаптер, HTTP transport, UI обложки/вложений, сквозные тесты.
PR остаётся Draft; готовность обложек и production не заявляется.
