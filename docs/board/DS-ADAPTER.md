# Board B1 — граница дизайн-системы и приложения

Основа: неизменённая IQUIPAGE 05.7, manifest SHA-256
`f252a499e00d7bab6088640126a406075a86bf109e673a257a002d8e90e9195c`.
Сборка проверяет каждый исходный файл перед копированием в .build/ds-candidate.

## Использованные публичные возможности

Точная композиция .kanban/.iq-board, .task-card, bindBoard; taskEmphasis/taskSignal,
иконки, avatar stack, file-empty, iq-dialog/drawer, iq-select, iq-combobox,
iq-date-field, iq-markdown-editor. Пример и редактор прочитаны в исходной поставке.
Три аватара +N используют одинаковый диаметр и кольцо из .iq-avatars.
Карточка не получает произвольную палитру или новую анимационную библиотеку.

## Ошибка приложения B-L01

Приложение ограничивало колонки flex-высотой, сжимая карточки до 30px и оставляя
текст за их границами. Исправление — естественная высота колонок/карточек внутри
одного scroll root. Это композиция приложения, не изменение исходной DS.

## Явный расширенный кандидат 0.6.0-board.1

Файл ds-extension/board-patches.mjs применяется только к копии исходников.
Третий аргумент bindBoard: resolvePlacement, canDrag, onDragStateChange.
Он нужен для совпадения drop preview с автоматической сортировкой, блокировки
повторного движения сохраняемой задачи и буферизации обновлений во время жеста.
Опции необязательны: прежний двухаргументный вызов работает без изменений.
Завершение запрещённого drop отменяется, ID в overlay экранируется.
Длительности/кривые читаются из DS tokens; используются transform/opacity.
