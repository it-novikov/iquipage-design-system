# Финальная проверка обложек перед подключением

Scope: добавить, заменить, снять необязательную обложку в документе задачи;
показать её в карточке; сохранить файл, текст и ссылки при отмене/ошибке.
Основа на старте: 12596cb, B2.1; повторный npm run verify: 167/113 PASS.
Это более свежая реализация, чем исторические BLOCKED-checkpoints.

Дополнительные обязательные случаи (фиксируются до исправлений):
1. Снятие обложки обновляет подпись и aria-pressed в списке вложений.
2. Две одновременные замены: последняя выбранная выигрывает, а не последний ответ.
3. Явное снятие/выбор существующего файла отменяет более раннее намерение загрузки.
4. Неподключённый адаптер показывает ограничение, не бесконечную загрузку.
5. Ошибка декодирования изображения не обозначается как готовый просмотр.
6. Закрытие/уход освобождает запросы и URL; действующие задачи не меняются.
7. Смешанные карточки сохраняют геометрию при обычном pointer DnD и scroll.

Повторить действующие server/browser/file:// сценарии и всю проверку.
Проверки на синтетических данных; self-review, не команда независимых агентов.
Визуальный язык: текущие IQUIPAGE кнопки/файлы/диалоги и токены движения.
Production auth/ACL/AV, провайдеры и нагрузка остаются отдельным scope.
Старые ZIP/HTML, исходный design-system/ и посторонние файлы не заменять.
Новая поставка: Board B2.1.1, тот же PR #2 без merge/deploy.
