# Board B2 — текущая поставка

## Подключено к интерфейсу и хранилищу
Теги/релизы/шаблоны в настройках проекта; выбор в задаче; создание релиза из задачи.
Независимые checklist IDs и пункты; Markdown не переписывается checkbox-действиями.
Обычные комментарии и треды с решением; ответы, resolve/reopen; порядок нерешённых.
Стабильный message ID для повторного запроса, отдельная версия обсуждения от task.
Связи depends/related и inverse caption; создание/удаление ребра не удаляет задачи.
Три видимых условия доски и существующий поиск; точные filtered/total column counts.
IndexedDB v2 сохраняет B1-данные; одинаковая валидация references в трёх хранилищах.

## Принятые технические решения
Серверные записи каталога валидируются до commit: имя, тип, цветовая роль, проект, архивность.
Шаблоны применяются при создании; ID списков генерируются заново; тип не затирает авторский текст.
Архив каталога сохраняет старые назначения, но не даёт назначать новые.
Права управления каталогами не выводятся из edit: отдельный canManageCatalogs, default false.
Треды выводятся порциями по 20. Создание reply editor отложено до раскрытия.
Обновление списка сохраняет существующие узлы редактора и текст несохранённого ответа.

## Приёмка
Точный итоговый fingerprint/числа — в deliveries/board-b2/Sprintique-Board-B2-Verification.json.
Сценарии B2: templates → task → две проверки → release/tags → reload; threads → reply → resolve;
link → inverse → unlink; filters; lost response → retry; concurrent task edit; IDB v1→v2.
Сохраняются прежние Maps и Board B1 regression suites. Assertions не заменены ради PASS;
выбор description editor уточнён по name, поскольку появились дополнительные Markdown-редакторы.
