# Доска B1 — контрольная точка реализации

Область: устранить наложение карточек, встроить новую навигацию, типы и базовые
отношения родителей/детей, согласовать сортировку с DnD и сохранить Maps R4.
Это первая исполняемая поставка общего плана B1–B5, не весь production scope.

## Написано и подключено

Reusable Board entry и стили отделены от demo-shell; задача хранится в общем repo.
Card containment, 200 карточек, общий scroll root и закреплённые шесть заголовков.
Нет общего счётчика, WIP, материалов, bulk и лишних типов; настройки возле профиля.
Guest landing и профиль явно демонстрационные, не серверная авторизация.
Сортировки priority/due/created/manual, контроль позиции до drop, локальные preferences.
Иерархия одного статуса, переход к детям других статусов, счётчики без дублей.
Три уникальных исполнителя дочерних +N, акценты DS, отсутствие source в документе.
Markdown drawer, описание/тип/статус/срок/ответственный/приоритет и searchable parent.
Закрытие dirty document требует решения. Смена родителя сохраняет ID и данные.
Проверка цикла/чужого проекта происходит в транзакции Memory/Browser/File repository.
События движения использовали и сохраняют существующий transactional outbox Maps.

## Доказательства

Новые Node-тесты: 14 в tests/board-model.test.mjs плюс прежние 87 тестов.
Новые browser suites: geometry (3), interactions (8), обычный pointer motion (3).
Старые Maps browser suites (20) не заменяются новыми. Точный итог — текущий
verification.json; PASS относится только к совпадающему sourceFingerprint.
Реальные устройства, screen reader, нагрузка 1000/10000 и production API не приняты.
Все данные тестов синтетические, базы временные. Работа выполнена одним агентом,
проверка — автоматические тесты и self-review, без заявления независимой команды.
