# B2.1 — вложения и необязательная обложка

Одобрено пользователем: обложка карточки и полной задачи на основе вложений.
База — Board B2, af79e0c; прошлые поставки не перезаписываются.

Task.attachmentIds содержит ID файлов; coverAttachmentId — null либо один из них.
Без обложки нет пустого блока. Снять обложку не означает удалить вложение.
Удаление файла-обложки снимает оба отношения при сохранении задачи.
Бинарные данные хранятся отдельно от JSON задачи: серверный blob store или IndexedDB.
Новые задачи получают ID до загрузки; staging не создаёт задачу автоматически.
Список вложений и обложка сохраняются вместе с задачей с проверкой версии.
Повтор загрузки с тем же ID и данными не создаёт дубликат.
Ошибка/отмена сохраняет старую обложку и текст задачи.
PNG/JPEG/WebP проходят декодирование; миниатюры отделены от оригиналов.
PDF/TXT и другие разрешённые документы — вложения, не обложки.
Внешние URL, SVG/HTML-превью, распаковка файлов и LLM не используются.

DS: supplied file-item/file-dropwell, IqFilePreview.file, кнопки и motion-токены.
AttachmentAdapter — транспорт платформы, не новый визуальный компонент DS.
Обложка — согласованная композиция img/button; исходная 05.7 не меняется.

Приёмка: upload/replace/remove/reload, новая задача без обложки, abort/retry,
конфликт версии, отказ диска, неверный формат, изоляция проекта, миграция IndexedDB,
light/dark/narrow, DnD смешанных карточек, lazy thumbnails, освобождение Blob URL.
Production ACL, AV/CDR и облачное хранилище требуют отдельной интеграции.

## Фактическая точка остановки
Сохранены чистая модель вложений/обложки, проверка форматов и отдельные процессоры
изображений для Node и браузера. Добавлены шесть тестов модели и Node-процессора.
Подключение хранения и визуальная часть НЕ РЕАЛИЗОВАНЫ.
Инструмент отклонил запись attachment-store.mjs, attachment-adapter.js и cover-view.js:
«Этот вызов инструмента был заблокирован OpenAI, поскольку мы не смогли определить
статус безопасности запроса». Эти файлы не созданы; их обход не выполняется.
Изменения действующего model.js/repository.js откачены к B2, чтобы не выпускать
неподключённую миграцию IndexedDB и не активировать незавершённые операции.
Ни загрузка, ни смена обложки через UI не объявляются рабочими.
Предыдущие B2 ZIP/HTML остаются последней готовой пользовательской поставкой.
