# Explicit acceptance gaps

No mandatory new DS capability was discovered in this packaging slice. Missing platform services are not DS gaps and are not replaced by fake repositories.

Open product scope: maps/documents, private media and cover pipeline, mutable task templates, non-parent task links, search, memberships, SSE/outbox worker, agent proposals/approval/execution and MCP, API response/OpenAPI completeness, deployment reliability and external pilot hardening.

Accessibility: the owner previously requested buttons without a focus-state distinction. Extraction preserves that approved source behavior; this is not a WCAG-conformance claim. Full keyboard/screen-reader/light-dark/reduced-motion review is pending.

Performance: illustration picker is now lazy; largest deferred chunk remains ~1.19 MB. There is no accepted FPS/latency/load target yet. Do not relabel bundle bytes as runtime performance acceptance.

Identity provider and deployment/storage providers are configuration decisions pending before an external pilot, not reasons to use a reference identity. Without required OIDC settings production startup refuses to run.
