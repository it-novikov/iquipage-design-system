# Property-list: исходное предложение дизайна

[proposal-initial.md](proposal-initial.md) — неизменённый авторский файл `property-list-reflow-design-proposal.md`, **36 403 B**, SHA-256 `bd5b12448a5f5f36b1851c28b27b097cb0332e62ca81fdf7358ec07a38371c7c`. Это предложение после discovery, а не утверждённый CSS/API и не результат native приёмки.

Цель — читать полную пару «подпись → значение» без открытия контрола или догадки по tooltip. Автор сопоставляет автоматический intrinsic reflow существующего wide-list с явно включаемым container mode и предварительно выбирает первый вариант для ограниченного rendered опыта. Цены обсуждаются отдельно: ритм и высота, полнота длинных подписей, ширина значения, риск ошибочной интеграции агентом и согласованность строк. Ни числовые бюджеты, ни новый layout ещё не приняты.

Основа предложения — DS54 и Task кандидата `6423443d71a0817570281cf28822a3c14f7db684` (tree `81fa1c…`, база `2c757009…`), не автоматически последующий main `4f181ff…` с PR84. [Baseline attempt 1](../baseline-attempt-1/README.md) сохранён отдельно с честным `FAILED` из-за измеряющего селектора; он не подтверждает и не отклоняет предложенный reflow. Новый вариант, browser acceptance и human usability в оригинале остаются `NOT_RUN`.
