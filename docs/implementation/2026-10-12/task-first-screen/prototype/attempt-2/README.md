## Точная локализация отказов

**Оценка: timeout после Escape, а не при открытии.** Оба стека указывают на `run.mjs:217:54`. В frozen runner этой позиции соответствует ожидание отсутствия открытого popover после Escape: `!document.querySelector('[popover]:popover-open')`. Предшествующие click и ожидание открытого popover на строке 216 завершились. SHA256 runner `44951fca53d840c819e590ed5492164935502c78205425339bcae110a3e945d8` совпадает с `fixtureSHA256` в исходном результате. Причина отказа отмены пока не установлена: нужны пассивные события открытия, фокуса, клавиатуры и закрытия в следующем отдельном запуске. Исходный oracle сохраняется.

Ранняя производная scratch metadata ошибочно называла этот отказ «at estimate native open». [Provenance](provenance.json) содержит явную поправку и привязку к frozen коду. Исходные JSON, журнал и кадры не переписаны.

**CTA: locator выбранной вкладки охватил другие выбранные элементы.** `[data-task-tabs] [aria-selected=true]` совпал с восемью элементами: вкладкой, options и ячейкой календаря. Это strict-mode отказ harness на строке 241. Следующий запуск должен ограничить выбор ролью `tab`; применение `first()` или принудительного клика не устраняет причину. Наличие выбранной вкладки в списке совпадений не заменяет незавершённые последующие assertions маршрута и фокуса.
