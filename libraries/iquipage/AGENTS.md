# IQUIPAGE library boundary

Independent source-owned Web Components package. Build/test with Node 24 and npm scripts. No Sprintique/domain/auth/server imports or root-workspace dependency. Expose reusable controls through public entries and matching declarations; keep advanced modules lazy.

The pinned historical design-system snapshot is not editable source. This library includes approved extensions, with provenance in PROVENANCE.json. After a public API change, update types, increment package version, build/test/pack, then let a consumer adopt that exact release. Never rewrite a consumed tarball in place. Public publishing needs separate authorization and resolved licensing.

No visual redesign during packaging work. Verify affected components in actual browser contexts, including compact editor and controlled decision actions. Tests do not replace manual screenshot inspection.
