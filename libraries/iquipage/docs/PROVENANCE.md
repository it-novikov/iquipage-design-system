# Происхождение исходников 05.5

Использованы доступный в беседе предварительный HTML 05.5 и полный архив 05.4. Из HTML без минификации извлечён читаемый реестр JavaScript-модулей и CSS. Исходный HTML SHA-256: `a078c486f89fe26f53a7d4927a6770b9837a7149bbd1d7d023203bf7d61ec5a4`.

Это восстановленные редактируемые JavaScript-исходники, не исходный TypeScript. Публичные декларации поставлены и проверяются отдельно. В 05.5 все исправления внесены в src; оба HTML, dist и SVG пересобираются скриптом. Скрипты/тесты 05.4 использованы как основание, но их прежние цифры не объявляются тестами 05.5. Часть текущих тестов использует внутренние методы для подготовки сценария; публичные интеграционные fixtures выделены отдельно.

42 модуля каталога, 30 runtime-модулей. `ui-demo.js`, `stories`, `app`, `sample-data` не находятся в ESM closure. Четыре группы base/light/dark/primitives равны принятому fixture 05.3, содержащему утверждённые токены; проверка — foundation-parity.json. Не заявляется равенство всех CSS-правил, так как исправлялись состояния и новая компоновка.

Иконки происходят из Lucide/Feather. Сохранены действующие лицензии `vendor/lucide/LICENSE`. Три новых SVG горизонтального выравнивания взяты из официальных исходников Lucide; хеши и источники — `vendor/lucide/alignment-provenance.json`. Вертикальные варианты поворачивают ту же геометрию. Шрифтовые файлы исключены.

Фирменный знак IQUIPAGE остаётся отдельной геометрией. Исторические медиа каталога — примеры для локального ознакомления, не лицензия на рекламную публикацию сторонних материалов. Тестовые иконки не заменены заглушками.

Удалённые репозитории и приложение Sprintique не изменялись. Нанятые специалисты, независимые респонденты, backend, многопользовательское редактирование и внешняя приёмка не подразумеваются этой поставкой.
