# IQUIPAGE 05.7 — отчёт о завершении

## Что сохранено

Поставка завершает предварительную 05.7 и замечания к визуальной доске. Существующий каталог, рабочий каркас, Markdown viewer, roadmap, graph и crop не пересоздавались. Группы `base/light/dark/primitives` токенов побайтно совпадают в нормализованном JSON с 05.6; версия обновлена отдельно. Никаких изменений в удалённом репозитории Sprintique не выполнено.

## Исправления по запросу

**Библиотека.** Три категории равной ширины, поиск, компактные строки записей и сетка силуэтов. Состояния selected/hover/focus проверены в сочетаниях. В ходе проверки обнаружен реальный конфликт тёмной темы: hover подавлял фон selected и оставлял тёмный текст. Hover теперь исключает selected и keyboard focus; фон и текст назначаются парой.

**Нижние инструменты.** Выбор, панорамирование, соединение, undo и redo используют фиксированные SVG-боксы и одинаковые области нажатия. Нет инструментов карандаша и списка в видимой панели. Порядок действий доступен через клавиатуру. Иконки не являются иконочным шрифтом.

**Подсказки.** Вместо конкурирующих `::after` используется один DOM tooltip с явными цветами. Он появляется по hover и клавиатурному фокусу, остаётся при переводе указателя на подсказку, закрывается Escape, действием, прокруткой и удалением компонента. Исправлен Escape при фокусе вне доски. `aria-describedby` прикрепляется только к текущему триггеру и удаляется без повреждения прежних ассоциаций. Это проверка конкретных сценариев, не сертификация доступности.

**Несколько мыслей.** Отдельные редактируемые карточки вместо обязательного текстового полотна; перестановка, удаление, Enter/Shift+Enter. Выбор области работает через настоящий supplied `iq-select`. Отменённый ввод восстанавливается. Поле мысли автоматически растёт до 224 px, затем прокручивается внутри; короткий текст возвращает компактную высоту. Импорт готового текста остаётся дополнительным, с явным разделением по строкам или абзацам. До commit размеры каждой будущей карточки измеряются общим Markdown renderer. Добавление группы — одно действие истории. Недоступная область не подменяется молча свободным местом.

**Связи.** Выбор четырёх сторон, привязка рядом с объектом, три типа линии, подпись, стрелки, пунктир и параметры. Проверены переподключение обоих концов, изменение через клавиатурную форму, отмена, JSON roundtrip и readonly. Линии обновляются в существующих SVG-группах. Размеры точек управления нормируются к экранным пикселям. Ствол маршрута для скошенной фигуры выводится за её ограничивающую рамку до поиска обхода.

**Фигуры и функциональная цепочка.** Четырнадцать общих определений геометрии, текста и якорей. У цепочки нет большой внешней рамки: события, проверка, решение, результат и обратная ветка различимы сами по себе. Никакой автоматизации такой пример не запускает. Все 14 фигур проверены с форматированным текстом и центральным выравниванием; прежние проверки остальных выравниваний сохранены отдельно.

**Дополнительный дефект.** Сохранение Markdown без изменения текста считалось no-op и оставляло textarea внутри объекта. Представление теперь восстанавливается даже при отсутствии новой записи истории.

## Что действительно улучшено в качестве реализации

Вначале были красные проверки, а не только обновлены селекторы. Реальные исправления: Escape tooltip вне доски, no-op finish Markdown, selected+hover/focus контраст, масштаб stroke у ручек, измерение Markdown перед размещением и отказ для исчезнувшей области.

Часть прежних тестов была некорректна относительно нового UI: выбор области трактовался как native select; текст SVG читался HTML-only методом; пустое место для добавления фигуры попадало на текстовый объект; старый router тест требовал именно нижний порт даже при намеренной смене маршрута. Они заменены действиями через существующие контролы и проверками смысла: выбранный parentId, реальный текст подписи, endpoints, конечная геометрия и обход препятствия. Контракты отказа/отмены не ослаблялись.

## Производительность и пределы

SVG-группы переиспользуются; обновление обзора не пересобирает всю сцену. На проверенных сценах после завершения действий нет работающих анимаций. `performance-057.json` показывает реальные синхронные JS-измерения, включая хвосты задержек. Он **не измеряет FPS, paint или физический экран**; быстрый viewport update не равен гарантии 60/120 FPS.

Полной виртуализации нет. Начальная отрисовка и пересчёт большого числа связей всё ещё могут быть заметными. Маршрутизатор учитывает максимум 40 ближайших препятствий и не гарантирует исключение всех пересечений в плотно наложенном графе. Прямая линия по определению не обходит объекты. Нет общего разведения всех подписей и всех связей друг от друга.

## Известные непроверенные области

Safari/WebKit touch, Firefox, реальные скринридеры и физические устройства не входят в прогон. Исходный запрос WebKit `tap` календаря остаётся отдельным пунктом внешней приёмки. Не проводились независимые пользовательские исследования, производственные серверные операции и одновременная работа команды. Успешные локальные тесты не закрывают эти задачи.
