# Передача IQUIPAGE 05.6 агенту внедрения

## Что поставить

Обновить vendor boundary целиком: `dist`, `types`, токены и лицензии из manifest. Публичные входы `core`, `advanced`, `whiteboard` остаются раздельными. `core` включает оба новых компонента. В `dist` нет catalog stories и демонстрационных данных. Не копировать CSS примера и не менять Shadow DOM.

## Матрица исходной заявки

| Требование | Поставленная возможность | Что проверить на стороне приложения |
| --- | --- | --- |
| Компактная общая композиция | `iq-work-layout density="compact"` и публичные slots; поддерживаемый `iq-work-header`; восемь ролей плотности | Ваша глобальная навигация + задачи/идеи/план/релизы/admin; 1280×720 и 1440×900; доступные рабочие строки без начальной прокрутки |
| Видимый проект и главное действие | Переносимый полный h1 и actions; опциональный sticky-header | Длинные реальные названия, denied CTA, модальные операции, возврат к списку |
| 390 px, клавиатура, 200% | Узкая композиция, сохранение focus/DOM identity; CSS zoom 2× и reflow проверены локально | Настоящее увеличение браузера и устройства; работа с вашей шапкой и сохранённым скроллом |
| Reader без chrome редактора | `iq-markdown-viewer` с `.value`, `.headingLevel`, `label`, `empty-text`, `code-wrap` | Передать то же строковое содержимое отчёта; не внедрять textarea/toolbar/counter/footer вручную |
| Тот же Markdown и безопасность | Общий `safeMarkdown()` для preview и viewer; HTML escaping; HTTPS/#; без resource auto-load | Реальная загрузка/доступ к отчёту; разрешённые ссылки приложения. HTTP/relative внешние URL намеренно не активируются |
| Не принимать результат просмотром | Viewer не посылает acceptance/change/submit событий | Принятие результата оставить отдельной предметной командой; не связывать открытие viewer со статусом задачи |

Исходный y≈638 — не эталон универсальной высоты и не замер нашего макета. Измерить итоговую геометрию вашего рабочего экрана, записать число видимых строк и проверить сценарий выбора первой задачи.

## Рекомендуемая замена

```js
import { registerCore } from './vendor/iquipage/dist/core.js';
registerCore();
const viewer = document.querySelector('iq-markdown-viewer');
viewer.value = report.markdown;  // после проверки права чтения
viewer.headingLevel = 2;        // ниже h1 страницы
```

Смена плотности выполняется через `layout.density`, а не масштабирование страницы и не привязка CSS к private-элементам. Для reports не использовать `iq-markdown-editor disabled` как замену чтению. Пустое значение reader не заменяет loading/error; эти состояния данных задаёт приложение поставленными сообщениями/индикаторами DS.

## Незакрытая внешняя приёмка

Текущий пакет не заявляет закрытие старого WebKit-touch запроса календаря: нового теста на этом движке нет. Также не заявляется проверка всех экранов настоящего Sprintique, main push или deploy. Приёмка — сначала manifest/import, затем предметные API/denied/conflict, visual/keyboard/touch и реальные браузеры.
