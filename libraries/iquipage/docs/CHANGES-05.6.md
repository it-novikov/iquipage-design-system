# Изменения 05.6

База: полный архив IQUIPAGE 05.5. Исходные архивы не изменены. Эта поставка относится к DS, не к удалённому репозиторию Sprintique.

## Компактный каркас рабочего экрана

- Добавлен публичный `iq-work-layout` с `compact` / `comfortable`, именованными slots и опциональным закреплением header.
- Плотность координирует существующий `iq-work-header`, навигацию, сводку, toolbar и данные. Полные названия переносятся.
- Смена плотности сохраняет DOM-идентичность дочерних узлов, введённые значения и фокус.
- Основные примеры каталога `workspace/tasks`, `workspace/board`, `workspace/plan` используют этот же публичный каркас с переключателем плотности, сохраняя собственные данные и операции.
- Добавлен отдельный `workbench.html`: задачи, идеи, настоящий roadmap, материалы релиза и административный список показывают общий ритм. Это локальные примеры, не подключение пяти реальных backend-модулей.
- Неизменные роли цвета и основная шкала интервалов сохранены; добавлены восемь зависимых ролей плотности.

## Markdown для чтения

- Добавлен `iq-markdown-viewer`, без chrome редактирования и предметных действий.
- Renderer выделен в единый модуль `markdown.js`. Preview и viewer используют один результат разметки и одинаковую типографику.
- Добавлены настоящие таблицы, сгруппированные/вложенные списки, заголовки до шестого уровня и аккуратная обработка fenced-кода.
- Установлена единая URL-политика; HTML экранируется. Изображения остаются ссылками, автоматических сетевых запросов renderer не делает.
- Широкие code/table прокручиваются внутри блока; код можно переключить на перенос через `code-wrap`.
- Значение до регистрации, пустой документ, реактивная замена и явный предел размера проверены.

## Обнаружено при проверке и исправлено

- Обращение к renderer до инициализации при переводе function export на shared-module import.
- Неопределённый токен `--iq-bg` в новой композиции: заменён существующим `--iq-canvas`. Закреплённая поверхность теперь непрозрачна в обеих темах и не зависит от цвета canvas браузера.
- Длинный технический перечень slots переполнял документацию каталога на 320 px; описание разбито на самостоятельные термины.
- Режимы отображения и блоки данных адаптируются не только к viewport, но и к ограниченной ширине контейнера.

Не добавлялись серверные операции, автоматическое принятие отчёта, новые палитры, перепроектирование доски или скрытая модификация Sprintique.
