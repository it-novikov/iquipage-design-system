# IQUIPAGE 05.7 — воспроизведение проверки

## Проверенная среда и идентичность

Все свежие результаты находятся в `evidence/verification-summary.json`, версии среды — в `evidence/environment.json`. Браузерные отчёты содержат SHA-256 точного HTML/CSS; снимки имеют отдельные inventory. Итоговый ZIP дополнительно проверяется по каждому файлу manifest.

Основная среда: Chromium 144.0.7559.96, Node 22.16.0, TypeScript 5.8.3. Интерфейс отрисовывался системным резервным шрифтом; внешние запросы блокировались. Контент загружен через `set_content`, потому что прямые переходы к localhost/file блокируются этой средой. Настоящие ESM-файлы загружались через request interception из `dist`, не подменялись моками компонентов.

Текущий номер 05.7 уже использовался для предварительного HTML. Проверять нужно SHA, не только надпись номера.

## Полный порядок

```bash
node scripts/build.mjs
python scripts/check057.py
python tests/workshop057.py --phase behavior
python tests/acceptance055.py
python tests/ui.py --phase behavior
python tests/everyday056.py --phase behavior
python tests/workshop057.py --phase layout
for w in 320 390 1280 1440; do python tests/ui.py --phase layout --width "$w"; done
python tests/contrast057.py
python tests/contrast056.py
python tests/performance057.py
python tests/workshop057.py --phase screens
python scripts/package057.py
python scripts/package057.py --verify
```

`check057.py` запускает `node --test tests/*.test.cjs` и пять настоящих строгих TypeScript fixtures: основной API, lazy import, whiteboard, everyday и 14 новых shape kinds. Команды и stderr сохраняются в JSON/TAP. Для сборки пакеты npm не нужны; для проверки требуются Python Playwright, установленный Chromium и tsc.

Новый тест допускает `CHROMIUM=/path/to/chromium`. Старые тесты используют `/usr/bin/chromium`; при переносе поменять только путь к движку. Параметр `--only` нужен для диагностики, но такой запуск не считается полным. Нельзя вручную исправлять `passed` или SHA.

## Что покрывают числа

- 209 unit checks — чистая логика, включая roadmap/graph, переносы/историю, safe Markdown, whiteboard и 28 новых проверок shapes/routing/capture. Один loop-case маршрутов охватывает 14 фигур × 3 стиля × 16 сочетаний сторон; он честно считается **одним** случаем, не тысячами отдельных тестов.
- 33 workshop browser checks — реальные действия подсказок, библиотеки, target area, отдельных мыслей и связей. Некоторые составные случаи имеют несколько проверяемых шагов. Fixtures данных используют публичные setters; часть внутренних вызовов применяется исключительно для диагностики геометрии, не предлагается как публичный API.
- 36/28/26 — повторные регрессии доски, каталога и рабочего каркаса/Markdown viewer соответственно.
- 84 layout cases — 7 сценариев/состояний × 6 ширин (320/390/768/1024/1280/1440) × 2 темы. Внутри — переполнение документа, библиотека и её категории, dock, диалог ввода и компактный редактор.
- 684 catalog checks — 171 проверка на каждую из четырёх ширин, обе темы. Это структура и горизонтальное переполнение, а не ручной просмотр 684 экранов.
- Контраст измеряется отдельно по реальным computed цветам с композицией alpha-фонов предков. Недоступные controls исключены; не измерены все пиксели антиалиасинга фигур и произвольные цвета пользовательского контента. Это не заявление о полной WCAG conformance.
- Performance — три простые сцены 16/64/120 объектов. Initial assignment включает forced layout, 15 JS-сэмплов после 3 прогревочных измерений. Показаны median и p95, не FPS и не worst-case плотного графа.

## Непокрытое и границы

Safari, Firefox, WebKit touch календаря, реальные скринридеры, физические мобильные устройства и серверные create/edit/reload/conflict не проверены этой поставкой. Нет автоматизированного полного визуального pixel-diff всех маршрутов. Отсутствие ошибок в выполненном прогоне не означает отсутствие всех возможных ошибок. Исследование удобства с независимыми людьми не проводилось.

Полная производственная доступность, мониторинг, API авторизация, realtime и хранение — часть приёмки продукта. Нельзя переносить результаты DS стенда на Sprintique без отдельного прогона. Для будущей работы использовать `docs/HANDOFF-05.7.md`.
