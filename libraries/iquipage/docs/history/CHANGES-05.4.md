# Изменения 05.4

Область: удобство свободной визуальной доски 05.3. Токены, темы и прежние компоненты дизайн-системы не переосмыслялись. Исполняемый workflow остаётся отдельным `iq-graph`.

## Быстрее начать

- Явная основная кнопка «Добавить заметку»: создаёт объект и сразу открывает текст.
- «+» в заголовке области добавляет запись именно в неё; следующая заметка сохраняет тему.
- Массовый ввод: счётчик, выбор области, запрет пустого подтверждения, возврат отменённого наброска.
- Коллизии учитываются при добавлении; области и вложенные области растут по содержимому.
- Постоянные подписи инструментов и конкретная инструкция текущего действия.
- Отдельный `whiteboard.html` для работы без навигации каталога.

## Понятнее управлять

- «Готово», «Ещё заметка», «Отменить ввод» при редактировании на холсте.
- Контекстная строка над холстом, не закрывающая выбранную запись.
- Выделить → упорядочить → собрать в именованную область.
- Перенос в область и создание связи через обычную форму, без обязательного drag.
- Поиск по тексту и переход к найденному объекту; навигация по областям.
- Шаблоны добавляются рядом с текущими данными и отменяются одним Undo.

## Довести до результата

- «В действие»: сохраняет ID и связи, позволяет уточнить следующий шаг и ответственного.
- Отдельная панель договорённостей и завершения действий.
- Markdown-итог и JSON содержат реальные текущие данные, а не скриншот.
- Таймер и личное голосование сохранены как локальные инструменты, без притворной командной синхронизации.

## Не терять работу

- Отдельные данные и обзор каждого сценария; пустая доска остаётся пустой.
- Явное состояние недоступного браузерного хранилища.
- Отмена, повтор, read-only, ожидание и конфликт сохраняют исходный controlled-контракт.
- Внезапное изменение прав во время ввода сохраняет локальную копию текста для экспорта.
- Подтверждение после отмены не меняет документ.

## Мобильные сценарии

- Чекбоксы для множественного выделения, та же группировка и перенос.
- Обычное редактирование текста отделено от расширенного ввода координат.
- Возврат фокуса к объекту после закрытия формы.
- Исправлены переполнение панели инструментов при 320 px и лишняя ширина столбца действий в списке.

## Публичный API

- Схема `iquipage.whiteboard/1` и независимые `data`, `selection`, `viewport` сохранены.
- Добавлено свойство `saveStatus` для предоставленного приложением статуса хранения.
- Экспорт `@iquipage/web/whiteboard` указывает на актуальный ES-модуль и `types/whiteboard.d.ts`.
- Сохранены поддержка управляемого подтверждения и защита от запоздалых ответов.

Точная область тестов находится в QA.md. Эмпирическое исследование с участниками не проводилось; гипотезы и протокол — UX-REVIEW-05.4.md.
