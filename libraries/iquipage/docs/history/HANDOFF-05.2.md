## Последовательность обновления

1. Проверить SHA-256 ZIP и MANIFEST.sha256. Оригинальную 04.9/05.1 не переписывать поверх без сохранения.
2. Обновить один vendor boundary: runtime и CSS **одной версии**. Не смешивать новый JS со старой палитрой.
3. Привязать адаптеры к публичным свойствам и событиям из EXTENSION-API.md. Не использовать приватные поля selectedId/session или патчи DOM.
4. Повторить adapter tests и реальные API-операции, включая отказ/конфликт/права. Ни один локальный пример не подтверждает API Sprintique.
5. Выполнить исходную независимую диагностику календаря в WebKit: standalone и dialog, mouse/touch/keyboard, обе темы. Если ошибка воспроизведётся, сохранить настоящий FAIL, не снимать фокус локальным обходом.
6. Проверить crop-профиль: получение File → выбор области → Blob → загрузка → сохранение/удаление. Подготовка Blob сама по себе не означает сохранение фото.

## Воспроизведение DS-диагностики

`python tests/release052.py --browser chromium` использует Chromium. При установленных соответствующих движках доступны `--browser webkit` и `--browser firefox`. Отсутствие движка приводит к ошибке запуска, а не к автоматически проходящему skip. Для установки: `python -m playwright install --with-deps chromium firefox webkit`.

В среде подготовки DNS для загрузки WebKit/Firefox был недоступен. Playwright WebKit не является установленным Safari: даже его успешный прогон не заменяет проверку пользовательской версии Safari. Сохраняется исходная граница приёмки из заявки.
