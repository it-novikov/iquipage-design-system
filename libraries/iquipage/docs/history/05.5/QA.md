## Визуальная проверка

12 свежих снимков произведены matrix055.py из текущего whiteboard.html. Просмотрены основные композиции: светлая доска с библиотекой/доком, схема и связи в тёмной теме, редактор с Markdown и мобильная панель. Отдельно автоматизированы размеры текстовых областей. Отступы и вся визуальная иерархия каждого произвольного пользовательского документа не могут быть подтверждены конечной матрицей.

Контраст новой доски измерен по computed foreground и alpha-composited solid backgrounds с учётом SVG face фигуры. Прежние свечения измерены по скриншоту с временно скрытым передним планом. Это не полный accessibility audit: все иконки, focus geometry, screenreader объявления и все комбинации не измерены.

## Что специально проверялось

Новая заметка наследует peer geometry; длинный текст не меняет width, соседняя запись смещается. Одинаковый текст при zoom 0.35 и 2 имеет одинаковую модельную высоту. Markdown заголовки/списки помещаются. Отмена возвращает точный документ. Длинное название области сдвигает детей; подпись изображения имеет отдельную высоту.

Связи: click-click, pointer drag, оба переподключаемых конца, точный keyboard-путь, отмена Escape во время жеста, стили/подпись/direction/dash, roundtrip и undo. 40 обновлений координат сохраняют DOM identity SVG-группы; это проверка механизма, не FPS.

Реальные ESM: core загружен первым и не регистрирует graph/roadmap/crop; затем advanced, board и полный entry без повторного определения customElements. Полный набор файлов запросов — esm-requests.json.

Права: локальный draft нельзя принять устаревшим callback после отзыва разрешения. Read denial не раскрывает текст/media в DOM, но геометрия остаётся доступной по отдельному праву. Проверены unknown domain fields после перемещения, field-level denial, отдельное редактирование/удаление relations без права create. Blob URL освобождается при отзыве чтения. Экспорт crop проверен по реальным пикселям, а не только по событию.

## Открытые границы

**P1 WebKit touch календаря не принят независимо.** Настоящие Chromium tap с has_touch=true на 390×844 проходят в standalone/dialog обеих тем; mouse/keyboard сохранены. Попытка установить WebKit завершилась EAI_AGAIN; лог включён. Это не WebKit, Safari и не iPhone. Нужен повтор исходного WebKit harness, который не предоставлен полностью.

Не проводились: реальные screenreader/user sessions, физический multi-touch/stylus, восстановление браузера после аварии, серверное хранение/авторизация/realtime, API Sprintique и реальная initial bundle-сборка проекта. Нет полной виртуализации или автоматического obstacle-free routing. Не гарантируется 60/120 fps на произвольном оборудовании. Локальное demo-хранилище не равно production синхронизации.
