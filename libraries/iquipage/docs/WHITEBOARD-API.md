# Визуальная доска / публичный контракт 05.7

## Подключение

```html
<link rel="stylesheet" href="./dist/iquipage.css">
<iq-whiteboard id="board"></iq-whiteboard>
<script type="module">
import { registerWhiteboard } from './dist/whiteboard.js';
registerWhiteboard();
const board = document.querySelector('#board');
board.data = {
  schema: 'iquipage.whiteboard/1', title: 'Ретроспектива', revision: 1,
  objects: [], connections: []
};
board.saveStatus = 'Локальная доска';
board.addEventListener('iq-change', ({detail}) => {
  // detail.value — полный новый документ. Хранение определяет приложение.
  console.log(detail.reason, detail.value);
});
</script>
```

Требуется браузер с Custom Elements. Для ES-модуля используйте HTTP/HTTPS. Автономные `index.html` и `whiteboard.html` содержат встроенный код и не требуют сервера или npm-установки. Условия браузерного хранилища для `file://` различаются; экспорт остаётся явным способом забрать работу.

## Данные

Схема `iquipage.whiteboard/1` сохранена; новые необязательные поля 05.5 описаны ниже. Типы объектов: `sticky`, `text`, `shape`, `frame`, `task`, `image`, `drawing`. Общие поля: `id`, `type`, `text`, `x`, `y`, `width`, `height`, `color`; дополнительные — `parentId`, `locked`, `author`.

Для задачи: `owner`, `done`. Для фигуры: `shape: rectangle | diamond | pill | ellipse | parallelogram | database | document | predefined | manual | trapezoid | hexagon | delay | connector | offpage`. Изображения хранятся как безопасный data URL PNG/JPEG/WebP; загрузка из UI ограничена 5 МБ. Рисунок содержит `points`. Связь: `id`, `from`, `to`, `label`, `style: curve | straight | elbow`, `arrow`.

`validateWhiteboard(value)` валидирует вход до применения. Координаты — модельные, не экранные. `selection` и `viewport` имеют отдельные setters. Внешняя установка этих свойств не создаёт обратного события выбора/обзора.

## Свойства

| Свойство | Назначение |
|---|---|
| `data` | Валидированный полный документ. Getter возвращает копию, а не доступ к внутреннему массиву |
| `selection` | Массив существующих ID объектов и связей |
| `viewport` | `{x,y,zoom}`, масштаб 0.2–2.5 |
| `view` | По умолчанию `canvas`. Старый программный `list` оставлен для совместимости API, но в новом видимом интерфейсе переключателя нет |
| `readOnly` | Запрет пользовательских изменений; поиск, обзор и экспорт остаются доступны |
| `state` | `ready`, `loading`, `error` |
| `controlled` | Включает явное подтверждение владельцем данных |
| `templates` | Массив `{id,title,description,data}`; шаблоны добавляются, не заменяя текущее содержимое |
| `saveStatus` | Текст состояния хранения, предоставляемый приложением. Ожидание, конфликт и readonly имеют приоритет |

Методы: `fit(ids?)`, `select(ids, announce?)`, `undo()`, `redo()`, `cancelPending()`, `fullscreen(open)`. Остальные методы исходников — детали реализации, не стабильный контракт интеграции.

## Управляемое сохранение

```js
board.controlled = true;
board.addEventListener('iq-change-request', async ({detail: request}) => {
  try {
    const response = await saveToYourApi(request.value, request.baseRevision);
    // response обязан содержать новую revision, большую baseRevision.
    if (request.accept(response)) board.saveStatus = 'Изменения сохранены';
  } catch (error) {
    request.reject('Не удалось сохранить. Можно повторить.');
  }
});
```

`saveToYourApi` здесь — функция приложения, а не предоставленный серверный адаптер. `accept()`/`reject()` возвращают `false` для устаревшего, повторного или отменённого ответа. Не считайте локальный предпросмотр подтверждённой записью в базу.

`iq-change-cancel` содержит `requestId` и `baseRevision`: приложение может отменить свой сетевой запрос. При поступлении внешней версии во время ввода или ожидания конфликтующая локальная копия сохраняется для экспорта. Автоматического merge и совместной синхронизации компонент не выполняет.

## События

`iq-change`: `{value, reason}` после локального изменения или принятого подтверждения. `iq-change-request`: `{requestId,baseRevision,value,reason,accept,reject}`. `iq-selection`: `{ids}`. `iq-viewport`: `{x,y,zoom}`. `iq-retry`: запрос повторной загрузки. `iq-announcement`: `{text}`. `iq-vote` всегда содержит `local: true` и не означает общий результат встречи.

## Доступные без drag операции

Добавление через кнопку и массовый ввод; переход к объектам через поиск и области; перемещение в область по названию; соединение по двум названиям; положение и размер через точные значения; изменение текста обычной формой. На холсте стрелки перемещают выбранное на 1 px, Shift — на 10 px, Alt — меняет размер. Enter открывает редактирование. Escape отменяет текущий ввод, жест или режим в зависимости от контекста.

## Хранение и миграция

Компонент не обращается к localStorage. Каталог демонстрирует отдельный адаптер локального хранения с пространством ключей `iq-whiteboard-055-*`. Документы из 05.3 импортируются через JSON без изменения схемы. Автоперенос между разными file:// URL или браузерами не обещается. Удалённый сервер, права, общий таймер, командное голосование и многопользовательское редактирование не реализованы.

## Пределы

Полной виртуализации нет. Массовая вставка ограничена 100 заметками за операцию. Редактируемый текст ограничен 10 000 знаками на объект; это техническая граница, не рекомендация превращать заметку в длинный документ. CSS-подсветка не заменяет текст состояния. Для сложных графов автоматизации используйте `iq-graph`, а не свободную доску.


## Геометрия текста и редактор 05.5

Объект принимает `align: 'left'|'center'|'right'`, `valign: 'top'|'middle'|'bottom'`, `autoHeight?:boolean`, `minHeight?:number`. Для областей: `layout?:'column'`, `headerHeight?:number`; для изображений — `captionHeight?:number`. Сохраняйте необязательные поля при roundtrip через сервер, а не пересобирайте только прежний поднабор.

Размеры, x/y и отступы принадлежат документу. Zoom влияет только на отображение. У заметки текст переносится в сохранённой ширине, а высота растёт по содержимому. Минимум запоминается отдельно. Для программно фиксированного `autoHeight:false` приложение отвечает за объём; редактор сохраняет весь исходный текст. Максимальная автоматически рассчитанная высота текстового тела — 4000 модельных px, общий предел объекта — 10000 px. Очень длинный материал следует открыть в редакторе или вынести в отдельный документ; 10000 знаков — технический предел, не рекомендуемая длина заметки.

Для областей вертикальное выравнивание относится к полосе заголовка, а не ко всей группе. У изображения — к подписи, у задачи — к текстовой части между служебными строками. Рамка выбора геометрии остаётся прямоугольной; реальная фигура и точки соединения учитывают форму.

Enter или действие «Редактировать» открывает текст. Ctrl/Cmd+Enter завершает; «Отменить ввод» возвращает исходный текст и размеры. Markdown хранится в `text`, не в произвольном DOM. HTML из вставки не исполняется. При конфликтующей внешней версии доступна локальная копия, но не выполняется скрытое объединение версий.

## Связи 05.5

```ts
interface BoardConnection {
 id: string; from: string; to: string; label?: string;
 style?: 'straight'|'curve'|'elbow';
 fromPort?: 'auto'|'top'|'right'|'bottom'|'left';
 toPort?: 'auto'|'top'|'right'|'bottom'|'left';
 arrow?: boolean;     // стрелка в конце
 arrowStart?: boolean;
 dashed?: boolean;
 color?: 'neutral'|'accent'|'success'|'warning'|'error';
 labelPosition?: number; // 0..1 вдоль маршрута
 bend?: number;          // дополнительное смещение маршрута
}
```

Видимые точки появляются у выбранного объекта. Можно потянуть от точки к другому объекту или нажать на две точки последовательно. Отдельный нижний инструмент позволяет выбрать два объекта без точного попадания в порт. Escape отменяет только текущий жест/режим до принятия. Выбранная связь открывает действие «Настроить связь» и две ручки переподключения; Enter/Space на ручке открывает точную форму.

Нельзя соединить объект с самим собой, создать повторную направленную пару или использовать заблокированный объект. Область и старый рисунок не являются конечной точкой связи. Удаление объекта удаляет его связи как часть того же изменения. Перенос сохраняет неизвестные поля доски только в пределах документированной модели; для доменных сущностей с произвольными полями предназначен iq-graph.

Кривая и ортогональная линия строятся по сторонам объектов. Это не профессиональный маршрутизатор обхода произвольных препятствий и не исполнитель бизнес-процесса. Обратную петлю можно направить стороной и смещением; направление/подпись не определяют исполнение на сервере.


## Изменения workshop 05.7

Общая модель данных и события сохранены. 14 видов фигуры описаны типом `BoardShape`. Их определения, insets и крепления едины. Новые виды должен понимать каждый потребитель документа; reader 05.6 не гарантирует сохранение нового силуэта.

Добавление нескольких мыслей теперь открывает отдельные карточки. Между карточками — Enter, строка внутри карточки — Shift+Enter. Поле назначения использует `iq-select`. Вставка текста требует явного выбора разбивки: строки или абзацы. До 100 карточек, до 10 000 знаков каждая; пустые значения не создаются. Это один атомарный `capture-batch`. При отказе набросок остаётся доступным для повторного открытия.

Библиотека слева: записи, фигуры, файлы; нижний dock управляет выбором/панорамированием/связью/историей. Tooltip имеет `role=tooltip`, появляется по hover/focus и закрывается Escape, не меняя модель. Дополнительные публичные методы для управления внутренними вкладками или tooltip намеренно не введены.

Связи поддерживают уже поставленные свойства и новый расчёт маршрута с ограниченным обходом. `style=straight` не избегает объектов; `curve/elbow` используют ограниченную геометрию ближайших 40 препятствий. Для переподключения есть перетаскивание конца и точная форма со списками источника/назначения. Настройка параметров через внутренний DOM не является API интеграции.
