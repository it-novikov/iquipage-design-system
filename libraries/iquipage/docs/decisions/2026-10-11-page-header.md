# ADR: slots названия и возврата в iq-work-header

Дата:2026-10-11. Статус: принято в рамках SPR37, авторизация владельца на публичное расширение DS. Выпуск0.6.0-vnext.44.

Проблема: страницы Sprintique используют разные заголовки, потому что обычного строкового title недостаточно для переключателя релиза/карты и возврата из профиля. Локальное копирование геометрии header привело к разным отступам и поведению действий на телефоне.

Решение: расширить существующий iq-work-header слотами title и back. Title принимает принадлежащий приложению h1 с нужным контролом, back — ссылку или кнопку возврата. Actions и context остаются совместимыми. Если title slot отсутствует, сохраняется прежний настоящий h1 из экранированного атрибута title. Узлы сохраняют identity, значения и обработчики; активный slotted control возвращает фокус после атрибутного render без прокрутки. Публичные spacing/title custom properties соблюдаются на viewport/container breakpoints.

Альтернативы: копировать внутренний DOM/CSS в продукте нарушает public boundary; создавать вторую header-сущность дублирует уже существующий контракт; переносить переключатели в отдельную соседнюю строку добавляет повтор названия и лишний шаг. Поэтому выбран минимальный совместимый слот.

Проверка: unit регрессия rich/plain title, escaping, identity и focus; вся DS suite, size gate без повышения бюджета; exact archive adoption и реальная проверка заголовков/действий на390px в обеих темах. Глобальная навигация остаётся ответственностью приложения, шапка страницы не подменяет auth/public shell. Обратимый rollback — вернуть exact предыдущую DS и её consumer composition одним изменением; публичный серверный API не затронут.
