# Task Light / спецификация

## Семантика

| Тип задачи | Приоритет | Свет |
|---|---|---|
| Любой | Критический | Красный |
| Любой | Высокий | Янтарный |
| Эпик | Обычный или низкий | Фиолетовый |
| Задача | Обычный или низкий | Отсутствует |

Статус, исполнитель, срок и положение в списке не участвуют в выборе цвета. Критический эпик получает красный, а не смешанный красно-фиолетовый фон. «Эпик» при этом остаётся текстом. Свет не заменяет отдельные состояния выбора, фокуса и перетаскивания.

## Отрисовка

`src/styles/task-light.css` содержит всю геометрию эффекта. `tokens/semantic.json` содержит три группы `task-light-{critical|high|epic}-{core|mid|rim}`, отдельно для каждой темы. `task-light-row-strength` ослабляет поле в строках списка. `task-light-meta` поддерживает контраст идентификаторов.

Карточка: непрозрачная нейтральная основа и два плавно затухающих поля. Строка: градиент рисуется на всей строке таблицы, поэтому между ячейками нет швов. На мобильном те же токены работают на вертикально собранной строке. У календарных записей эффект не применяется.

Слой наведения — псевдоэлемент `::after` с `pointer-events:none`, под текстом. Он не растягивает размер карточки и не перекрывает интерактивные элементы. Нет фильтра `blur`, canvas, WebGL, анимируемых градиентов, циклической анимации, отдельного `requestAnimationFrame` или постоянно назначенного `will-change` ради подсветки. Существующий цикл перетаскивания работает только при переносе.

## Контроль качества

Не наращивайте насыщенность изменением базового фона каждой задачи. Не возвращайте левую полосу, тень наружу или разноцветные поля в зависимости от статуса. При изменении токенов повторите проверку контраста **после композиции** на реальном фоне: сравнения одного HEX с другим недостаточно для прозрачных градиентов.

В текущем прогоне снимки фона получены при скрытом тексте, но неизменной геометрии. Для каждого текстового прямоугольника проверены 15 точек, включая состояния покоя и наведения. Это ограниченная консервативная выборка, не формальный аудит всей доступности приложения.
