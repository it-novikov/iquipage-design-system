Действующая база и сервисы не менялись. Перед фактической выкладкой нужна свежая копия.

## Условия выпуска

Выкладка допускается после полной проверки неизменного исходного дерева, независимого ревью исправленного результата без P0/P1, проверки браузерного сценария и точного архива IQUIPAGE. Для образа сохраняются полный Git SHA и digest. Миграция выполняется отдельным контейнером с миграционной ролью; API и worker не получают её credentials. После включения `agent_work` проверяются готовность, отсутствие перезапусков и рабочий сценарий от собственного аккаунта Codex.

## Откат

Миграция 077 добавляет таблицы и право `work.write`. Старый образ `931e09d` не является совместимым откатом после её применения: он проверяет прежнюю историю миграций и не знает нового права. Подмена тега без восстановления базы запрещена.

Отключение `agent_work` возвращает прежнюю навигацию и закрывает новые маршруты, сохраняя данные. При необходимости остановить API-исполнителей отдельно устанавливается `SPRINTIQUE_AI_RUNNERS=0`. Это выключение функции, а не доказательство возможности откатить весь сервер. Оно должно быть проверено на изолированном стенде с новой схемой до выпуска.

При отказе самого сервера требуется совместимый проверенный образ либо восстановление базы и исходной конфигурации. Полное восстановление выполняется при остановленных API и worker; записи после резервной копии предварительно сохраняются и оцениваются, чтобы не потерять пользовательскую работу. Непроверенный старый образ не используется как быстрый обход.

Финальные SHA, digest, результаты проверок и наблюдения заполняются после реальной приёмки и выкладки. Наличие этой записи не означает, что выпуск готов или выполнен.
