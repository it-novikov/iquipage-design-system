# Независимое ревью SPR-14

Проверен локальный diff модуля work, V77/afterMigrate, MCP tools, интеграции AgentRunner/AgentTools и связанных HTTP тестов. Production, деплой и OAuth конфигурация не менялись. Ревью backend выполнено чтением; отдельно добавлены независимые проверки отмены и зависимостей.

## Исправления, проверенные по коду

| Условие | Результат |
| --- | --- |
| Повтор старой команды после чужих изменений | Receipt возвращает исходную revision и исходный token только для claim, требует reload; не подменяет их текущими. Обычный GET token не раскрывает. |
| Отмена внешнего агента | Старый token теряет силу; после завершения собственных поручений новый claim требует нового поручения человека. Первичный импорт черновика без прежних поручений сохранён. |
| Потеря прав инициатора | Каждый новый service change проверяет инициатора живых поручений. Человек с правом остановки может отменить работу после потери прав прежнего инициатора. |
| Критерии и одобрение | Агент не меняет текст критериев. Одобрение требует человека, другого автора и точного результата, доказательств и критериев; digest включает эти поля. Новое изменение сбрасывает одобрение. |
| API завершение без actor | Lifecycle policy ограничена точным владельцем таблицы и временным scope проекта запуска. Definer восстанавливает прежний scope; runtime не получает owner/BYPASSRLS. Project lock предшествует run lock. Завершение обновляет session/event/audit/outbox; lease освобождается, если нет другого живого поручения того же аккаунта. |
| Новые права после миграции | Изменённые пользователем presets не расширяются автоматически. |
| Bridge | Сохраняет raw импорт и неизвестные разделы, игнорирует заголовки внутри fenced blocks; active/doing и критерии согласованы с локальным форматом. Импорт подтверждённых результатов отклоняется. |
| Зависимости | Сохранение и добавление шага отклоняют неизвестные ссылки и циклы. Начало/завершение шага требует завершённых предшественников. |
| Навыки | Версия создаётся один раз, session фиксирует digest. External MCP инструменты допустимы; API setup проверяет requiredTools по фактически доступным инструментам и текущим правам для всех путей запуска. |
| Повторное обращение во время запуска | С session связан только исходный `source_message_id`. Более позднее обращение остаётся pending без session, пока его не обработают отдельно. |
| Поручение человека для API | Конкретная goal и выбранное обсуждение передаются как отдельный ограниченный `workInstruction` внутри untrusted user data. Ответ направляется в выбранное обсуждение. |

Каталог LIMIT 100 не скрывает доступные аккаунты: действующий предел workspace — 50, grant проекта ограничен тем же workspace.
