# UX and design-system alignment (September 2026)

Private DS **0.6.0-vnext.23**. It covers the component audit of the whole Sprintique UI and the changes the owner approved.

## Owner decisions

| Question | Decision |
|---|---|
| Button focus | Ring shown for keyboard focus only (`:focus-visible`), not after a mouse click. |
| Saving a task | Existing tasks save each field automatically. A new task is still created with an explicit button. |
| Assignee | Only a current human project member can be the assignee. |
| Board admission | The rule stays the same. The board explains tasks that are waiting for a planned release. |

## Known gaps

- DS-GAP-FIN-1 (missing capability): no text field with suggestions that also accepts a new value. `iq-combobox` only picks from its options. The finance category is a DS text field with a native `datalist` of the categories already in use; the browser draws the suggestion list.
- DS-GAP-FIN-2 (DS defect): `ui.textarea` renders a character counter (`data-count`), but only the DS catalogue script updates it; `enhance()` does not. The finance dialogs update the counter themselves.
- DS-GAP-FIN-3 (missing component): no compact figure tile for a row of totals. `.iq-metric` is a catalogue-scale card (36–64px figures, demo `metric-*` parts). Finance places `dl` facts on `--iq-surface` tiles with DS type and radius tokens. There is no currency-aware amount field either: the amount is a DS text field with `inputmode="decimal"` and the DS input suffix for the currency sign.

- On the board, the drag handle inside a card is smaller than 44px on touch screens. The whole card surface is still a tap target.
- In a hidden or background browser tab, DS dialogs finish closing only once their close animation runs, because Web Animations pause while the tab is hidden. Visible tabs are not affected.
- DS-GAP-F (missing component): no tile with the label over the value. The task drawer stacks each `.iq-properties[data-columns]` field (`.tdr-facts`, `.tdr-fact`, `.tdr-span-2`, `.tdr-span-all`); the hero row sets its values at 500 through `.iq-select-value` and `[data-date-caption]`. Labels keep the DS property size (13px) rather than the 12px caption of the handoff, since the DS label is not the product's to restyle.
- DS-GAP-G (missing component): no `iq-date-range-field`. The drawer's plan uses a product composition (`ui/src/board/plan-field.js`, `plan-range.js`): the DS date trigger and date popup surface, a range calendar, typed ends, presets and a help line on DS tokens. The Planning schedule dialog still uses two `iq-date-field`.
- DS-GAP-J (missing capability): a select value cannot wrap to two lines, and a long label is clipped without an ellipsis because `.iq-select-value` is a flex box. The drawer gives `.iq-select-label` an ellipsis and keeps `.iq-select-meta` in view; the full name is in the open list.
- DS-GAP-L (missing capability): the inline tag picker always shows "Ещё тег" after chosen tags and has no "Ещё N" overflow; the drawer shows every tag, wrapping.
- DS-GAP-M (missing capability): `iq-date-field` always shows its calendar glyph and has no read-only text state (`readonly` disables the trigger). Dates in the facts keep the glyph; read-only facts are product text.
