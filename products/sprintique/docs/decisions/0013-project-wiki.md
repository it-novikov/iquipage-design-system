# Документация проекта

SPR-17, 2026-10-11. Это контракт реализации; работающий выпуск подтверждается отдельными проверками.

Владелец подтвердил TASKS_READ для чтения и TASKS_WRITE для изменения, включая сервисные аккаунты. Каждое чтение страницы, архива, версии, поиска и связи проверяет проект и текущие права инициатора. OAuth MCP audience не используется для REST. Публичных страниц и отдельных ограничений страниц в этом выпуске нет.

Страница имеет стабильный id, projectId, parentId, title, body Markdown, revision, archivedAt, createdAt, updatedAt и updatedBy. PUT передаёт полный title/body/parentId/archived с baseRevision и Idempotency-Key; скрытое сохранение чужих полей не производится. Каждая успешная запись добавляет неизменяемую версию и атомарный audit/outbox. История не удаляется при восстановлении: восстановление создаёт очередную ревизию, возвращает title/body выбранной версии и сохраняет текущее место в дереве. Конфликт никогда не перезаписывается автоматически.

Общие изменения страниц сериализуются существующим проектным lock. Родитель должен быть активной страницей того же проекта; запрещены циклы и глубина более12. Нельзя архивировать родителя с активными дочерними страницами: их сначала перемещают или архивируют. Восстановление из архива проверяет родителя заново; при архивном родителе требуется явное перемещение. Нельзя создать сразу архивную страницу. Прямая ссылка на архив остаётся читаемой и сообщает о состоянии.

Каталог возвращает полное ограниченное дерево метаданных до1000 страниц, включая архив только в явно выбранном режиме; превышение — ошибка, а не обрезание. Текст не входит в каталог. Название до200 знаков, body до100000, поиск до200; история и поиск постраничные по50. Поиск использует существующую PostgreSQL simple tokenization, находит русские и латинские слова без обещания морфологии или поиска по части слова. Курсор связывается с проектом и запросом. Исторические версии не имеют придуманного срока удаления.

Связь задачи со страницей — отдельная типизированная привязка taskId/pageId, с собственной ревизией и обратимым архивом. Удаление связи не удаляет страницу. Чтение обеих сторон использует TASKS_READ, изменение — TASKS_WRITE и открытый результат задачи. Обратные ссылки показывают только доступные задачи; архив страницы узнаваем. Внешние ссылки SPR-16 сохраняют свою модель и не становятся отношениями задача→задача.

Собственные вложения wiki и совместное редактирование в реальном времени не включены. Существующий Markdown renderer не исполняет HTML и не обещает встроенные изображения; первый выпуск использует текст и безопасные ссылки. Файлы задач остаются в своих существующих вложениях. Wiki-текст для агента — недоверенные данные, а не источник полномочий.

Новые аддитивные таблицы имеют FORCE RLS; версии доступны только для INSERT/SELECT, изменения и удаления истории не предоставляются runtime. Для high поставки проверяется свежая и существующая база, CAS/retry, read-only/service scope, отзыв прав инициатора, циклы, глубина, архив и восстановление. Старый strict ledger несовместим: нужен заранее проверенный прежний интерфейс с новым совместимым backend/ledger и сохранением новых данных, затем backup и наблюдение. Down migration с потерей истории не используется.
