# W5. «Жду», `checkBackAt`, отложенные запросы и `neededBy`

- **Статус:** accepted
- **Дата:** 2026-09-29
- **Основание:** delivery-plan §3.3, §3.4, §5; solution-brief §7, §11; ответы владельца в design-handoff §2

## Решение

### «Жду»

1. `app.task_wait_state` — личное отношение (W2): кто ждёт, ожидаемый исполнитель, `source_sequence` (событие назначения, если отношение предложено при назначении), `check_back_at` (дата), `state active | resolved | cancelled`, `revision`.
2. **Создаётся только явно:** кнопкой «Следить за результатом» после назначения задачи другому человеку в drawer или действием «Жду результат». Автор задачи в «Жду» автоматически не попадает; `created_by` не вводится.
3. Ожидаемый исполнитель — текущий исполнитель задачи, не сам человек. Задача без исполнителя или своя — `422 WAIT_OWNER`.
4. **Жизненный цикл:** переназначение не меняет отношение, строка показывает «Сейчас исполняет …» (причина `delegated_reassigned`); завершение — причина `delegated_completed` («работа завершена»), отношение не закрывается само: человек принимает результат (`resolve`) или прекращает контроль (`cancel`). Повторное открытие задачи решённое отношение не возвращает — нужно снова «Жду». Исполнитель ушёл из проекта — `delegated_orphaned` без его имени.
5. `checkBackAt` — личная дата проверки, не срок задачи; в «Плане» — отдельный вид времени «Проверить».
6. Команды: `POST …/wait-state` (начать или начать снова, `baseRevision`), `PATCH …/wait-state` (дата), `POST …/wait-state/resolve` (`outcome: resolved | cancelled`). `DELETE` не используется: прекращение контроля — состояние с квитанцией, а не удаление.

### Отложенные запросы

7. Откладывание — поле `snoozed_until` личного состояния задачи (W3), доступно, пока у человека есть открытый запрос по задаче. Срок — от сейчас до 30 дней.
8. **Запрос с `neededBy` откладывается только до начала дня `neededBy`** в часовом поясе проекта (`422 SNOOZE_AFTER_NEEDED_BY`). Наступивший `neededBy` возвращает запрос в «Нужно действие» без действий человека.
9. **Новый запрос пробивает откладывание:** скрываются только запросы, созданные до момента откладывания.
10. Отложенные доступны списком «Отложенные: N» в шапке секции и отменяются одной командой (`until: null`) — это и «Отменить» из тоста.

### Время в «Плане»

11. `GET /api/v1/workbench/plan?horizon=today|7d&timezone=…`: `due` и `plannedStart/End` задачи, `neededBy` запроса, `checkBackAt` ожидания и вехи проекта — разные виды с подписью; даты без времени показываются без времени. «Сегодня» и «7 дней» — календарные дни в выбранном часовом поясе (граница — местная полночь, переход на летнее время не сдвигает дни). Часовой пояс выбирается и хранится в `app.workbench_preferences`; без выбора — пояс браузера с пометкой. Просроченные свои сроки, ответы и проверки попадают в «Сегодня» с тоном «просрочено». Фокус без дат — группа «Без времени».
