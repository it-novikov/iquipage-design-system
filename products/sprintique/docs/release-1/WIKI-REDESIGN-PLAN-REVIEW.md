## Финальный проход: APPROVE плана и потенциального дизайна

Независимо перечитана последняя revision2 и fresh4320. Все WDR1-1/2/3 и дополнительное reader menu замечание закрыты. Reader navigation в архив сохраняет роль: нет create/edit/menu/restore. Mobile conflict tabs сохраняют введённый собственный текст; peer move показывает новое место, peer archive имеет отдельно названное «Восстановить с моим текстом». При архивном родителе предлагается выбрать действующий раздел/корень. Пустое создание, длинное имя/ограничение глубины и distinct архивный detail представлены.

Оглавление собственным переходом сфокусировало H2 «Когда работа закончена», прокрутило документ, hash остался пустым; proposed public API в плане сохраняет production hash и ограничивает поиск своим viewer. Task→wiki surface просмотрен desktop и390px: вход из задачи, поиск/различение одинаковых имён путями, already-linked состояние, выбор→две строки, отдельное снятие связи, «Вернуть» и открытие страницы. Это mock переходы, не API запись. Scope входит в SPR-17 этого выпуска, не отложен.

Проверены proposed draft preview и возврат к правке; synthetic preview показывает текст без настоящего Markdown parse, что не является будущей реализацией: обязательна публичная editor/viewer preview семантика. Мобильный review footer прокручивается горизонтально только как инструмент ревью; в продукт его не включать. Focus trap/return, dialog keyboard, stale replies, dirty guards, IME, rights/CAS/accepted-task restrictions, pagination и1000page performance ещё не доказаны прототипом. Они остаются обязательными implementation gates, вместе с повторным визуальным просмотром настоящего нового DS document editor в обеих темах.

Одобряется именно план и потенциальная композиция, без открытых P1/P2 препятствий началу согласованной реализации. Не одобряются ещё не созданный runtime, новый DS выпуск, доставка или production. Public DS01–04 должны пройти отдельный контрактный review, exact adoption и неизменные Linux budgets. После реализации нужны собственные browser сценарии, freeze и два независимых review/root fullgate.
