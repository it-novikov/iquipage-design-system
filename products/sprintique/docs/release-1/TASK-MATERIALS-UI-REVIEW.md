В заполненной группе видны первые три названия и домены, остальные открываются через disclosure. Ссылка открывается непосредственно в новой вкладке; меню содержит изменение и удаление привязки. Новые ссылки вводятся через общую продуктовую форму с возможностью «Добавить и ещё».

Публичной DS .44 достаточно: section, menu, buttons, fields, dialog adapter, native anchor/details, work-details, skeleton и helper. Нового DS-контракта и внутренних переопределений нет. CSS отвечает за геометрию строк, перенос длинных названий и компактное пустое состояние. Отступы заголовка задачи не изменялись. Exact .45 adoption после общей поставки выполняет root; API .44/.45 одинаков.

## Сохранение и жизненный цикл

Материал использует отдельную revision, не переписывая задачу или Markdown. При создании задачи ссылки подготовлены локально; createTaskOnce создаёт задачу, затем команды сохраняют материалы и связи. Частичный отказ сохраняет drawer и черновики. Повтор отправляет только несохранённые материалы с прежними ID. Потерянный ответ не создаёт второй материал; конфликт с отличающейся или архивной записью требует явного сравнения в форме. Поля не стираются при отказе прав или сети.

Удаление архивирует привязку. «Вернуть» использует revision ответа. Если архивная запись успела измениться, UI предлагает вернуть актуальную версию после повторного явного действия. Внешний документ не изменяется. URL хранится как trim исходного значения: HTTP(S), без данных входа, пробелов и обратного слеша; максимум 2048 символа и 2048 UTF-8 байта. Дубликат определяется точным URL внутри категории, не семантической эквивалентностью адресов.

Подписка taskMaterials фильтрует projectId/taskId и принимает project resync без taskId. Запоздавший GET не заменяет более свежий; несохранённые черновики не затираются обновлением. Закрытие прерывает запросы, снимает подписку и enhancement listeners. Сохранение, повторное действие, смена задачи и уход со страницы учитывают busy/dirty. Принятый результат и читатель не получают контролов записи; сервер остаётся границей авторизации.
