# Проверка интерфейса релиза 1.0

11 октября 2026. Проверяет Codex через встроенный браузер, собственный одноразовый стенд PostgreSQL/S3; production-данные и человеческий аккаунт не используются. Первый проход на localhost:4312, окончательный проход .42 на новом стенде записывается ниже. Исходный стенд SPR-14 на 4311 не считается доказательством этой версии.

| Сценарий | Наблюдение |
| --- | --- |
| Связанный вопрос в обсуждении | Варианты и комментарий доступны, подтверждение сохраняет решение; после reload ответ остаётся в исходном треде, вопрос закрыт. |
| Поиск связи | Пустой запрос показывает текущий релиз, завершённые скрыты; запрос «следующий» находит задачу другого релиза. |
| Шаблон новой задачи | Task→bug меняет шаблон; создание с нетронутым шаблоном сохраняет пустое описание (SPR-12). |
| Шаблон сохранённой задачи | Пустое описание получает epic template; авторский текст переживает смену типа, предложение замены открывает подтверждение, отмена сохраняет текст. |
| Блокировка | Задача из текущего релиза заблокирована зависимостью вне видимой доски; завершение зависимости убирает сигнал без перезагрузки страницы. |
| Переходы | Board→planning→maps→finance→agents→settings→workbench→board сохраняют одну общую навигацию и contextual actions; staging host имеет opacity:0 и visibility:hidden. |
| Мобильный экран | 390×844: общий header доступен, navigation прокручивается до активного раздела; finance/agents/settings не вызывают горизонтального overflow страницы. |
| Темы и уведомление | Светлая и тёмная темы проверены; уведомление создания показывается с действием «Открыть», затем исчезает. Точная политика 3500 ms и паузы покрываются тестами DS. |

Снимки находятся в `output/release1-ui/`. Проверка loader основана на видимом переходе и состоянии staging DOM; это не запись всех кадров при искусственном замедлении сети. Права read-only, competing revision, accepted/backlog и tenant denial дополнительно проверяются HTTP/модельными тестами и независимым ревью; не выдаются за отдельно выполненные browser-сценарии.

Окончательный стенд .42 на localhost:4313: подтверждение ответа выполнено через Enter. Во время запроса фокус остаётся в article исходного треда; после успеха переходит на H3 «Кому передать следующий шаг?», а не на body. Ответ сохранён в том же обсуждении. Группа завершённых задач раскрывается через Enter, её заголовок виден один раз; дополнительная legend доступна только скринридеру. Снимки `task-final-dark.jpg` и `link-picker-dark.jpg` подтверждают текущую композицию. Production-приёмка ещё не выполнена.
