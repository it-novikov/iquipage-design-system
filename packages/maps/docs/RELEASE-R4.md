# IQUIPAGE Maps R4 — запуск, проверка и интеграция

Поставка переиспользуемого модуля и локального стенда. Не production-релиз Sprintique.
Исходная IQUIPAGE 05.7 сохранена; её расширение собирается в отдельном каталоге.

## Открыть

Для просмотра: `IQUIPAGE-Maps-R4.html`. Работает без сети, сохраняет в IndexedDB.
Автоматизация по событиям требует сервера; отсутствие сервера отображается в интерфейсе.

Для сервера (Node.js >=20):

```sh
cd IQUIPAGE-Maps-R4/packages/maps
npm test
npm run dev
```

Открыть `http://127.0.0.1:4317/`; отдельная оболочка — `?standalone=1`.
Рабочая база `.dev-state/` не входит в архив. Не удаляйте её при обновлении.
Можно задать отдельный `MAPS_DATA_DIR`. Сервер принимает запросы только на localhost.

## Проверить сборку

`npm run build` сверяет исходную DS с закреплённым манифестом перед сборкой.
Для браузера: `npm ci --ignore-scripts`, `npx --no-install playwright install chromium`.
Затем `npm run verify` и `npm run package`. Также поддерживаются предоставленные средой
`MAPS_PLAYWRIGHT_MODULE` и `MAPS_CHROMIUM_PATH`. Тесты создают только временные базы.

## Что изменилось после R3

События теперь сохраняют вход отдельно для каждого правила в той же операции, что и запись.
Правки карты после события не меняют уже принятые данные. Ошибка диска или конфликт версии
не публикует событие. Возобновление после сбоя не дублирует существующий запуск или задачу.
Завершающее правило сессии исполняется только из доверенной очереди с точной версией архива;
внешние events/webhooks не получают этого разрешения. Архив остаётся неизменяемым.

Журнал доставки показывает состояние отдельно от состояния запуска. После пяти ошибок
доставка останавливается; возможны три явных ручных повтора с проверкой версии или закрытие.
Неисправное правило не препятствует другим получателям того же события. История ограничена
500 результатами; в журнал не копируются содержимое заметок, секреты и полные сценарии.

## Доказательства

`packages/maps/evidence/final/verification.json` — результат итогового прогона.
`fingerprint.json` связывает его с точными исходниками, тестами и lock-файлом.
`MANIFEST.sha256` проверяет каждый файл архива. `archive-recheck.json` рядом с ZIP
появляется только после повторной сборки и тестов в чисто распакованной папке.
Старые логи R2/R3 и первоначальные FAIL сохранены как история, не как текущий вердикт.

## Интеграционные границы

Навигацию, проект, права, Repository и Runtime предоставляет host через `mountMaps`.
Не переносите демонстрационную оболочку как реальную маршрутизацию Sprintique.
Production-авторизация, ACL, распределённая очередь, совместное редактирование и общие
голоса/таймер требуют сервисов платформы. LLM использует серверный gateway и ссылку
на подключение; live-вызовы без его настройки не выполняются. Реальные touch-устройства,
скринридеры и Safari не приняты этим прогоном. Публикация/слияние PR/деплой не выполнялись.
