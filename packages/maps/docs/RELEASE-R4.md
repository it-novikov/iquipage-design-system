# IQUIPAGE Maps R4 — модуль и локальный исполнитель

Поставка объединяет интерфейс R3 и проверенную событийную автоматизацию. Промежуточные ветки не нужны для запуска.

## Открыть

`IQUIPAGE-Maps-R4.html` открывается с диска без сервера: карты, шаблоны, задачи и ручные сценарии сохраняются в IndexedDB браузера. Расписание и входящие запросы требуют серверного режима.

Для сервера (Node.js 20+, для воспроизведения CI — Node.js 22):

```sh
cd IQUIPAGE-Maps-R4/packages/maps
npm test
npm run dev
```

Адрес: `http://127.0.0.1:4317/`. По умолчанию открывается доска задач. `?standalone=1` открывает самостоятельную оболочку карт.

## Проверить и пересобрать

```sh
npm ci --ignore-scripts
npx --no-install playwright install chromium
npm run verify
```

Команда собирает кандидат DS и автономный HTML, запускает тесты модели/HTTP/очереди, браузерные сценарии и проверку файла HTML. Тесты создают временные базы и не используют рабочую `.dev-state`. Результаты — `artifacts/final/verification.json` и исходные логи. `npm run build` проверяет исходную 05.7 по манифесту, не меняя её.

Интеграционный API описан в `docs/INTEGRATION.md` и `types/index.d.ts`. Навигация, проект, права, хранение и исполнитель передаются хозяином приложения. Нельзя считать пример оболочки готовым production-интерфейсом Sprintique.

## События

Изменение карты, завершение сессии и переход задачи между колонками сохраняют событие вместе с записью. Входные данные и версия правила закреплены: последующие изменения карты не меняют ранее принятое событие.

Правило, заранее включённое для завершения своей сессии, может обработать доверенное событие архивации. Произвольный HTTP-запрос не получает это исключение. Другие запуски архивной карты и её редактирование запрещены. Создание задач всегда требует подтверждения.

Журнал: «Сценарий действий → Автоматизация → Доставка событий». Передача исполнителю не равна завершению сценария. В журнале доступны ссылка на запуск, остановленная доставка, явный повтор и закрытие события. Подробный контракт — `EVENTS-CONTRACT.md`.

## Границы

Готовы переиспользуемый модуль и однопроцессный локальный исполнитель. Отсутствуют production-подключение Sprintique, серверная многопользовательская авторизация, распределённая очередь/БД и совместное редактирование. Таймер и голоса локальные. Внешний LLM подключается через серверный gateway; live-вызовы в приёмке не выполняются.

Настройки и материалы платформы — точки интеграции, а не имитация серверов. Секреты не вводятся в узлы карты. Локальный сервер привязан к loopback; его нельзя публиковать в интернете как production API.

Самопроверка не заменяет независимое ревью, аудит скринридеров и реальные сенсорные устройства. Точный набор пройденных проверок, версии браузеров и ограничения находятся в приложенном отчёте.
