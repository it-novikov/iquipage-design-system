# Продолжение после R4

Актуальная поставка и инструкции: [RELEASE-R4.md](RELEASE-R4.md). Все зависимости объединены в `feature/maps-complete`. Отдельные исходники из старых ответов и неполные R2-папки больше не являются источником сборки.

Перед правками: проверить git status, исходный DS manifest и `npm run verify`. Модель, HTTP, очередь и браузерная приёмка исполняются на временных данных. Не перезаписывать рабочую `.dev-state`.

События: [EVENTS-CONTRACT.md](EVENTS-CONTRACT.md). Не снимать archived guard целиком и не заменять сохранённый вход текущей картой при повторе. Любой новый шаг с внешней записью должен оставаться после подтверждения и поддерживать идемпотентность.

Отдельный проектный этап — production-интеграция: согласовать репозиторий и окружение Sprintique, подключить router, ACL, task API, storage, LLM gateway, при необходимости realtime. Reference identity и файловую очередь не выставлять наружу как production API. Этот этап не маскируется локальными PASS.
