# IQUIPAGE Maps — R3, проверенная локальная поставка

Дата: 10 сентября 2026. Этот документ заменяет статус поставки R2 для данного архива.
Репозиторий: it-novikov/iquipage-design-system. Ветка: feature/maps-r3-release.
Рабочая ветка feature/maps-r3-usability сохраняет отдельный черновик очереди событий.
В R3 не включён непроверенный outbox; автоматические доменные события после записи
документа остаются следующим этапом, а не объявленной готовой возможностью.

## Запуск после распаковки

В каталоге IQUIPAGE-Maps-R3/packages/maps выполните `npm test`, затем `npm run dev`.
Стенд откроется по адресу http://127.0.0.1:4317. Node.js: 20 или новее.
Режим отдельного приложения: http://127.0.0.1:4317/?standalone=1.
Для запуска без сервера откройте IQUIPAGE-Maps-R3.html. Он хранит данные в браузере.
Автономный HTML не исполняет серверные расписания и не содержит подключения к LLM.

## Воспроизведение сборки и проверок

Архив сохраняет структуру monorepo и включает исходную design-system/05.7.
`npm run build` проверяет её SHA и собирает отдельный DS candidate; baseline не меняется.
`node scripts/preview.mjs` собирает автономный HTML без внешних зависимостей.
`node scripts/test-browser.mjs` поднимает временный сервер с изолированной базой,
выполняет 13 браузерных проверок и завершает только свои процессы.
`node tests/preview-smoke.mjs` проверяет file://, браузерное хранение и отсутствие сети.
Playwright задаётся через MAPS_PLAYWRIGHT_MODULE, браузер — MAPS_CHROMIUM_PATH;
без этих переменных используется установленный пакет playwright и его Chromium.

Подтверждено: 62 Node-теста, 13 browser-сценариев, offline smoke без HTTP-запросов.
Скринридеры, реальные touch-устройства, API Sprintique и live LLM не проверялись.
Весь review — self-review; production deploy не выполнялся.
