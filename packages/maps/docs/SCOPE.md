# Maps — область реализации R2

Основание: сообщение владельца от 10.09.2026. Реализация согласована с уточнениями: карта — фича платформы, а не её единственный экран; навигация Sprintique сохраняется; шаблоны должны быть понятны неспециалисту; событийная автоматизация входит как минимум в UI, контракты и воспроизводимый стенд; результаты фиксируются в отдельной ветке и на авторизованном Mac.

## Граница продукта

Модуль получает project, repository, permissions, integrations и обработчики переходов извне. Он не владеет глобальной навигацией, авторизацией или маршрутами Sprintique. Примеры platform и standalone используют один модуль. Доска задач, настройки и другие разделы остаются доступны над картой. Полноэкранный модальный режим не включается автоматически.

## Граница поставки

База: IQUIPAGE 0.5.7, commit 1932c2464e695ac7d7e020f2551317943d78a73f. Исходная папка design-system/ и release lock остаются неизменёнными. Необходимые расширения публичного canvas API оформляются как отдельный DS source candidate, собираемый в изолированной .build, а не как app CSS override или monkeypatch прототипа. Кандидат не объявляется новой поставкой 05.7.

Ветка: feature/maps-platform-module в it-novikov/iquipage-design-system. Изменения main, deploy, публикация npm и платные API-вызовы не разрешены этой задачей. Репозитории Sprintique используются только для изучения интеграционных границ; их рабочий код не меняется.

## Порядок checkpoints

1. Контракты, модель и публичное DS-расширение.
2. Рабочая поверхность, постоянные и сессионные карты, архив, библиотека и свои шаблоны.
3. Исполняемые цепочки, настройки событий и локальный reference runtime.
4. Проверки, evidence и инструкции следующему агенту.

Сохранение в локальном reference adapter не означает production-интеграцию Sprintique. В интерфейсе нет выдуманных участников или фиктивного успешного LLM-вызова. Неподключённая возможность явно обозначается.

## Обязательные проверки

Навигация и восстановление контекста; встроенный и отдельный режим; заполнение доступной площади; справка и возврат фокуса; создание/редактирование/reload/undo; конфликт версий и отказ записи; неизменяемый архив; продолжение сессии без изменения оригинала; создание/применение/экспорт шаблона; изоляция проектов; проверка графа; тест без внешних эффектов; сохранённое подтверждение; повтор события без второго запуска; валидация правил; явная недоступность неподключённого сервиса; светлая/тёмная тема; узкий экран; клавиатура; неизменность исходной DS.

Не заявляются без отдельной проверки: production auth, CRDT, реальные внешние подключения, независимое UX-исследование и production-ready deployment.
