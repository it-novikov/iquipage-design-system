Браузерная навигация к собственному localhost заблокирована net::ERR_BLOCKED_BY_ADMINISTRATOR: browser QA остаётся BLOCKED, не PASS. Live LLM и production-интеграция Sprintique не выполнены.

## Граница продукта

Maps — переиспользуемая фича, не владелец глобального shell. Навигация задач, настроек и других разделов предоставляется host. Локальная task-board оболочка в архиве показывает реальные задачи reference-стенда, а не production-задачи Sprintique. Ключи/ACL/маршруты платформы не имитируются.

## Следующий шаг исполнителя

Перенести полные исходники из архива в packages/maps, сохранив пользовательские изменения. Не включать .dev-state, node_modules, .venv, токены и шрифты. Выполнить npm run build, npm test и browser-сценарии tests/ui.py в разрешённой среде. После проверки сделать обычные коммиты в feature/maps-platform-module. Не изменять main, не выполнять force push или deploy.
