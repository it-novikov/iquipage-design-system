# Sprintique Board — снимок для ревью файлового слоя

Это полный снимок исходников, а не завершённая версия доски с обложками.
Пользовательская часть остаётся B1/B2; новые файловые адаптеры проверены на уровне контрактов.

## Подключено
Совместная фиксация задачи, attachmentIds, coverAttachmentId и жизненного цикла вложений
в MemoryRepository, FileRepository и BrowserRepository. IndexedDB обновлена до версии 3.
BrowserAttachmentAdapter сохраняет оригинал/миниатюры отдельными Blob и поддерживает
идемпотентный повтор, чтение, отмену и очистку временных файлов.

## Не подключено
HTTP-роутер ещё не включён в server/app.mjs. В задаче нет управления файлами/обложкой,
а доска не использует cover-loader.js. Эти операции записи были отклонены инструментом.
HTTP-модули синтаксически проверены, но не прошли сквозную HTTP-приёмку.

## Проверка
С Node.js 22 и установленным Chromium для Playwright:

```bash
cd packages/maps
npm ci --ignore-scripts --no-fund --no-audit
npx --no-install playwright install chromium
npm run verify
```

Тесты используют временные данные. Журналы находятся в evidence/final/.
Включённый HTML — регрессионный просмотр B1/B2 без интерфейса обложек.
Исходная DS не менялась; шрифты, секреты и рабочие базы в архив не включаются.
Последняя готовая поставка: deliveries/board-b2 в репозитории. PR #2 остаётся Draft.
