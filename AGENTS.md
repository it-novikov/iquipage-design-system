# Правила работы с репозиторием IQUIPAGE

## Инженерная система и мост

- Общие правила всех проектов — [engineering/README.md](engineering/README.md): принципы, стек, архитектура, имена, тесты, процесс по уровням риска, ревью.
- Работа над задачей идёт через мост: `engineering/bridge/bin/bridge brief` покажет открытую задачу. Протокол — [engineering/bridge/PROTOCOL.md](engineering/bridge/PROTOCOL.md): claim, контрольные точки после каждого законченного куска, итог шага с доказательством, handoff в конце сессии.
- Всё, что следующему агенту нужно знать, записывается в карточку задачи, а не остаётся в чате.

## Перед началом UI-задачи

1. Прочитайте `START-HERE.md` в корне.
2. Для задачи по новой функции начните с `iquipage-discovery`.
3. Для аудита существующего интерфейса используйте `iquipage-experience-audit`.
4. Для внедрения согласованного решения используйте `iquipage-implement`.
5. Для финальной проверки используйте `iquipage-review`.

Читайте только релевантный skill, актуальную problem/finding card и точный DS recipe. Для Sprintique — [индекс опыта](products/sprintique/docs/experience/README.md). Причины, варианты и приёмка дополняют существующую карточку; отдельный discovery для ясной разрешённой правки не нужен.

## Границы

- Дизайн-система развивается в `libraries/iquipage` через версии и упакованные релизы; продукт подключает только релиз из своего `vendor/` ([границы](docs/BOUNDARIES.md)).
- Не выдавайте тестовые результаты за production-приёмку.
- Не копируйте секреты в промпты, отчёты, фикстуры и примеры.
- Review по умолчанию read-only; исправления выполняются только в согласованном scope.

## Структура

- `libraries/iquipage/` — исходники дизайн-системы 0.6 (текущая линия, правила в её `AGENTS.md`).
- `products/sprintique/` — самостоятельный продукт на DS (правила в его `AGENTS.md`).
- `docs/BOUNDARIES.md` — границы DS и продукта, порядок изменений.
- `agent-skills/` — полный переносимый комплект скиллов и его проверки.
- `engineering/` — инженерная система и мост; `.bridge/` — карточки задач.
- `.agents/skills/` — проектная копия четырёх скиллов для Codex.
