# Правила работы с репозиторием IQUIPAGE

## Перед началом

1. Прочитайте `START-HERE.md` в корне.
2. Для задачи по новой функции начните с `iquipage-discovery`.
3. Для аудита существующего интерфейса используйте `iquipage-experience-audit`.
4. Для внедрения согласованного решения используйте `iquipage-implement`.
5. Для финальной проверки используйте `iquipage-review`.

## Границы

- Не меняйте историческую поставку `design-system/` и pinned SHA без явного решения владельца. Дизайн-система развивается в `libraries/iquipage` через версии и упакованные релизы.
- Не выдавайте тестовые результаты за production-приёмку.
- Не копируйте секреты в промпты, отчёты, фикстуры и примеры.
- Review по умолчанию read-only; исправления выполняются только в согласованном scope.

## Структура

- `libraries/iquipage/` — исходники дизайн-системы 0.6 (текущая линия, правила в её `AGENTS.md`).
- `products/sprintique/` — самостоятельный продукт на DS (правила в его `AGENTS.md`).
- `docs/vnext/STATUS.md` и `HANDOFF.md` — текущее состояние, открытые PR, запуск и порядок выпуска.
- `design-system/` — неизменённая историческая поставка IQUIPAGE 05.7.
- `agent-skills/` — полный переносимый комплект скиллов и его проверки.
- `.agents/skills/` — проектная копия четырёх скиллов для Codex.
