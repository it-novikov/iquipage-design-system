# IQUIPAGE Agent Skills 1.1.0

[С чего начать](START-HERE.md) · [Ревью 1.0](docs/REVIEW-1.0.md) · [Проверки](docs/QUALITY.md)

Четыре самостоятельных Agent Skills: problem-first discovery, аудит опыта, концептуальное внедрение и приёмка. Сохранены обязательные требования владельца: полный функциональный UI на принятой DS; отсутствие локальных подмен; гармония, ясность и управляемость для людей и агентов.

Версия 1.1 изменяет процесс и инструменты скиллов, НЕ дизайн-систему. Основа — неизменённая @iquipage/web 0.5.7 с pinned archive/manifest. Отдельно предоставляются scripts, schemas и evidence synthetic tests; готовность конкретного продукта ими не заявляется.

Ключевые изменения: scoped acceptance plan; проверка актуальности и связи findings с re-tests; более строгий schema validation; сокращённые рабочие инструкции и resume state; явная применимость проверок; безопаснее вывод кандидатов и network capture; конкретная design-review rubric.
