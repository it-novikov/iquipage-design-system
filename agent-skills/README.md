# IQUIPAGE Agent Skills 1.2.0

[С чего начать](START-HERE.md) · [Ревью 1.0](docs/REVIEW-1.0.md) · [Проверки](docs/QUALITY.md)

Четыре самостоятельных Agent Skills: problem-first discovery, аудит опыта, концептуальное внедрение и приёмка. Сохранены обязательные требования владельца: полный функциональный UI на принятой DS; отсутствие локальных подмен; гармония, ясность и управляемость для людей и агентов.

Версия 1.2 дополняет существующий brief проверкой причин, изменяемыми предпосылками, осмысленными вариантами и решением упростить/не строить. Это изменение процесса, не DS. Исторический baseline @iquipage/web 0.5.7 и его archive/manifest сохранены; текущую поставку определяют по конкретному продукту. Assessment schema 2.0 не меняется.

Ключевые изменения: scoped acceptance plan; проверка актуальности и связи findings с re-tests; более строгий schema validation; сокращённые рабочие инструкции и resume state; явная применимость проверок; безопаснее вывод кандидатов и network capture; конкретная design-review rubric.

Проверки и отчёты 1.0/1.1 — исторические материалы. Новые authored model cases остаются NOT_RUN, пока не выполнены реальные задания. Наличие skill, schema или зелёного manifest не доказывает качество UI либо агента. [Поддержание копий](docs/TOOLS.md) выполняется явно; установка не запускает новые процессы.
