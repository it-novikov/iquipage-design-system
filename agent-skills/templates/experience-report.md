# Аудит опыта IQUIPAGE
Статус: экспертный аудит / наблюдаемое исследование (указать реально проведённое).
Основание: source/revision, поверхности, роли, сценарии, ограничения.

## Краткий вывод
Какая работа затруднена; что перестроить первым; какой выигрыш является гипотезой.

## Модель продукта и текущий путь
Рабочие объекты, отношения, навигация; новичок/эксперт/агент.
Что сохранять; что согласовать. Приложить journey-matrix.csv.

## Находки
ID / evidence / confidence / цель пользователя / место сбоя / последствия /
предлагаемый путь и композиция / DS coverage / метрика или task acceptance / owner.
Отделять наблюдаемые баги от гипотез удобства и вкусовых предпочтений.
Для спорных причин добавить альтернативное объяснение и различающую проверку. Отдельно назвать гарантии и изменяемые решения; не принимать нынешний UI за единственную модель продукта.

## Целевое решение
До → после для каждого важного journey. Primary action, рабочая область, secondary data,
feedback/error/recovery и human approval. Все relevant states, а не один happy screenshot.
Для неоднозначного решения: baseline и осмысленные варианты, включая исправление существующего/упрощение/отсутствие новой функции; критерий до опыта, возможное опровержение, итог и оставшееся неизвестное. Точечному багу не нужны искусственные альтернативы.

## Понятность работы с агентами
Мандат, инициатор, роль, scope, статус выполнения/результата/сохранения, остановка,
источники и артефакты. Никаких выводов о backend, если он не проверен.

## Проверка с участниками (план, если не проводилась)
Группы, доступ/согласие, 5–7 заданий без подсказок, success criteria, время/ошибки/возвраты,
послетестовые вопросы. Предложенный размер выборки — гипотеза, не уже проведённая сессия.

## Передача
Приоритетный backlog, DS-GAP, вопросы владельцу, approved scope, связь с review finding IDs.
Реестр всех согласованных семейств с источником и фактически пройденным сценарным scope; не маркировать семью проверенной по одному screenshot. Общий inventory не задерживает bounded исправление подтверждённого критического пути.
