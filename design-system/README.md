# IQUIPAGE 05.7

Завершение whiteboard workshop: библиотека объектов, нижние инструменты, подсказки, отдельные карточки массового ввода, 14 фигур и редактирование связей. Утверждённые базовые токены 05.6 сохранены. Это Web-дизайн-система, не новая сборка приложения Sprintique.

## Открыть без установки

- `whiteboard.html` — отдельная визуальная доска.
- `index.html` — полный каталог компонентов, примеров и правил.
- `workbench.html` — компактная рабочая композиция и чтение Markdown.

HTML содержат код и стили. При недоступности внешнего Inter используется системный шрифт. Шрифтовые файлы не включены. Для первых двух действий не нужны npm, локальный сервер или серверный API. Хранение в браузере — только демонстрация, а не производственное сохранение; предусмотрены JSON-экспорт и явное сообщение при недоступности хранилища.

## Передать другому агенту

**Начните с `docs/HANDOFF-05.7.md`.** В нём указаны карта исходников, точные исправления, причины дефектов, контракт данных, миграционные ограничения, команды проверки и известные границы. Проверяйте контрольные суммы: предварительный HTML уже имел тот же номер 05.7.

- `docs/QUALITY-REPORT.md` — что сделано и фактически проверено.
- `docs/QA.md` — воспроизведение и границы результатов.
- `docs/WHITEBOARD-API.md` — публичная модель доски.
- `docs/INTEGRATION.md` — раздельные ESM-входы.
- `evidence/verification-summary.json` — результаты точной сборки.
- `docs/SOURCE-PROVENANCE.json` — исходные архив и HTML, из которых восстановлен комплект.

## Сборка и проверка

```sh
node scripts/build.mjs
python scripts/check057.py
python tests/workshop057.py
python tests/workshop057.py --phase layout
python tests/workshop057.py --phase screens
python tests/contrast057.py
python scripts/package057.py
python scripts/package057.py --verify
```

Для сборки нужен Node >=20, без npm-зависимостей. Для тестов нужны Python Playwright, Chromium и TypeScript. Полный порядок, включая регрессии и снимки, находится в `docs/QA.md`. Другой Chromium можно указать через `CHROMIUM` в новых тестах; старые регрессии используют `/usr/bin/chromium`.

## Подключение

Подключите `dist/iquipage.css` и нужный вход: `dist/core.js`, `dist/advanced.js` или `dist/whiteboard.js`. Полный `dist/iquipage.js` сохранён для совместимости. ESM обслуживается через HTTP(S), не посредством `file://`. Не смешивать JS и CSS разных поставок. Данные примеров, каталог и приложение не входят в ESM runtime.

## Границы

Реальная серверная интеграция, совместное редактирование, CRDT, BPMN-исполнение и полная виртуализация холста не реализуются этим пакетом. Маршрутизатор ограничен 40 ближайшими препятствиями, не решает все пересечения плотного графа. Автоматизированные прогоны выполнены в Chromium, не в Safari/Firefox и не на физических устройствах. Исследование с независимыми пользователями не проводилось.
